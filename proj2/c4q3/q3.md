좋아, 지금까지 만든 프로그램의 전체 실행 흐름을 **실행 순서대로 단계별로 설명**해줄게. 이 프로그램은 센서 데이터를 생성하고, 큐를 통해 비동기적으로 DB에 저장한 뒤, 종료 시 그래프로 시각화하는 구조야.
이 코드는 스마트팜 환경에서 센서 데이터를 수집하고 저장하며, 시각화까지 자동으로 처리하는 시스템을 구현한 것입니다. 전체적인 구조와 기능을 요약하면 다음과 같습니다:

---

### 🧠 주요 구성 요소

#### 1. **센서 시뮬레이션 (`ParmSensor`)**
- 온도, 조도, 습도 데이터를 무작위로 생성합니다.
- `SetData()`로 값을 설정하고 `GetData()`로 반환합니다.

#### 2. **큐 시스템 (`NodeQueue`)**
- 센서 데이터를 안전하게 저장하고 꺼내기 위한 FIFO 큐입니다.
- 멀티 쓰레드 환경에서도 동기화를 위해 `threading.Lock()`을 사용합니다.

#### 3. **데이터베이스 처리**
- SQLite를 사용하여 `parm_data` 테이블에 센서 데이터를 저장합니다.
- `insert_sensor_data()`로 삽입하고, `get_sensor_data()`로 조회합니다.

#### 4. **멀티 쓰레드 작업**
- `sensor_worker`: 각 센서가 2초마다 데이터를 생성하고 큐에 넣습니다.
- `db_worker`: 큐에서 데이터를 꺼내 DB에 저장합니다.
- `stop_event`를 통해 쓰레드 종료를 제어합니다.

#### 5. **시각화 (`plot_sensor_data`)**
- 시간대별 평균 온도를 센서별로 선 그래프로 표시합니다.
- 습도가 90 이상인 시간대는 빨간색 선으로 강조합니다.
- 결과는 `sensor_plot.png`로 저장됩니다.

---

### 📌 실행 흐름 요약

1. 센서 객체 5개 생성 (`Parm-1` ~ `Parm-5`)
2. 각 센서에 대해 쓰레드 실행 → 센서 데이터 생성 및 큐에 저장
3. DB 쓰레드 실행 → 큐에서 데이터 꺼내 DB에 저장
4. 사용자 입력으로 `'q'`를 입력하면 모든 쓰레드 종료
5. 종료 후 DB 데이터를 기반으로 그래프 생성 및 저장

---

### ✅ 개선 아이디어

- **DB 테이블 생성 코드 추가**: `parm_data` 테이블이 없을 경우 자동 생성하도록 보완 가능
- **예외 처리**: DB 연결 실패, 쓰레드 오류 등에 대한 예외 처리 추가
- **실시간 시각화**: matplotlib 대신 `plotly`나 `dash`를 활용하면 웹 기반 실시간 시각화도 가능
- **센서 데이터 범위 조정**: 실제 환경에 맞게 센서 값 범위를 조정하거나 센서 종류 추가

## 🧭 전체 실행 순서 요약

### 1. 프로그램 시작
```python
if __name__ == '__main__':
    main()
```
- Python이 이 파일을 직접 실행하면 `main()` 함수가 호출됨.

---

### 2. `main()` 함수 실행
```python
def main():
    stop_event = threading.Event()
    sensors = [ParmSensor(f"Parm-{i}") for i in range(1, 6)]
    ...
```
- `stop_event`: 쓰레드 종료를 제어하는 이벤트 객체 생성
- `ParmSensor` 객체 5개 생성 (Parm-1 ~ Parm-5)

---

### 3. 센서 쓰레드 시작
```python
for sensor in sensors:
    t = threading.Thread(target=sensor_worker, args=(sensor, stop_event))
    t.start()
```
- 각 센서마다 `sensor_worker()` 쓰레드 실행
- 센서 쓰레드는 2초마다:
  - 무작위로 온도, 조도, 습도 생성
  - 생성된 데이터를 큐(`sensorQ`)에 저장
  - 습도 90 이상이면 빨간색으로 콘솔에 출력

---

### 4. DB 쓰레드 시작
```python
db_thread = threading.Thread(target=db_worker, args=(stop_event,))
db_thread.start()
```
- `db_worker()` 쓰레드 실행
- 1초마다 큐에서 데이터를 꺼내 SQLite DB에 저장

---

### 5. 사용자 입력 대기
```python
while True:
    user_input = input()
    if user_input.strip().lower() == 'q':
        stop_event.set()
        break
```
- 사용자로부터 `q` 입력이 들어올 때까지 대기
- `q` 입력 시 `stop_event`를 설정하여 모든 쓰레드 종료 유도

---

### 6. 모든 쓰레드 종료 대기
```python
for t in threads:
    t.join()
```
- 센서 쓰레드와 DB 쓰레드가 종료될 때까지 기다림

---

### 7. 그래프 시각화 실행
```python
plot_sensor_data()
```
- DB에서 모든 센서 데이터를 조회
- 센서별로 시간대별 평균 온도를 계산
- 습도 90 이상인 시간대는 빨간 선으로 표시
- 그래프를 `sensor_plot.png`로 저장
