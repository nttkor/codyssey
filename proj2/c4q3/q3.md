좋아, 지금까지 만든 프로그램의 전체 실행 흐름을 **실행 순서대로 단계별로 설명**해줄게. 이 프로그램은 센서 데이터를 생성하고, 큐를 통해 비동기적으로 DB에 저장한 뒤, 종료 시 그래프로 시각화하는 구조야.

---

## 🧭 전체 실행 순서 요약

### 1. 프로그램 시작
```python
if __name__ == '__main__':
    main()
```
- Python이 이 파일을 직접 실행하면 `main()` 함수가 호출됨.

---

### 2. `main()` 함수 실행
```python
def main():
    stop_event = threading.Event()
    sensors = [ParmSensor(f"Parm-{i}") for i in range(1, 6)]
    ...
```
- `stop_event`: 쓰레드 종료를 제어하는 이벤트 객체 생성
- `ParmSensor` 객체 5개 생성 (Parm-1 ~ Parm-5)

---

### 3. 센서 쓰레드 시작
```python
for sensor in sensors:
    t = threading.Thread(target=sensor_worker, args=(sensor, stop_event))
    t.start()
```
- 각 센서마다 `sensor_worker()` 쓰레드 실행
- 센서 쓰레드는 2초마다:
  - 무작위로 온도, 조도, 습도 생성
  - 생성된 데이터를 큐(`sensorQ`)에 저장
  - 습도 90 이상이면 빨간색으로 콘솔에 출력

---

### 4. DB 쓰레드 시작
```python
db_thread = threading.Thread(target=db_worker, args=(stop_event,))
db_thread.start()
```
- `db_worker()` 쓰레드 실행
- 1초마다 큐에서 데이터를 꺼내 SQLite DB에 저장

---

### 5. 사용자 입력 대기
```python
while True:
    user_input = input()
    if user_input.strip().lower() == 'q':
        stop_event.set()
        break
```
- 사용자로부터 `q` 입력이 들어올 때까지 대기
- `q` 입력 시 `stop_event`를 설정하여 모든 쓰레드 종료 유도

---

### 6. 모든 쓰레드 종료 대기
```python
for t in threads:
    t.join()
```
- 센서 쓰레드와 DB 쓰레드가 종료될 때까지 기다림

---

### 7. 그래프 시각화 실행
```python
plot_sensor_data()
```
- DB에서 모든 센서 데이터를 조회
- 센서별로 시간대별 평균 온도를 계산
- 습도 90 이상인 시간대는 빨간 선으로 표시
- 그래프를 `sensor_plot.png`로 저장

---

## 📦 보조 함수 실행 흐름

### `sensor_worker(sensor, stop_event)`
- 센서 데이터를 생성하고 큐에 저장
- 습도 90 이상이면 빨간색으로 출력

### `db_worker(stop_event)`
- 큐에서 데이터를 꺼내 DB에 저장

### `insert_sensor_data(...)`
- SQLite에 센서 데이터를 삽입

### `get_sensor_data()`
- DB에서 모든 센서 데이터를 조회

### `plot_sensor_data()`
- 시간대별 평균 온도 계산
- 습도 90 이상이면 빨간 선
- 그래프를 이미지로 저장

---

## 🧠 전체 흐름 요약

```
main()
 ├─ 생성: 센서 객체 5개
 ├─ 실행: 센서 쓰레드 → 센서 데이터 생성 → 큐에 저장
 ├─ 실행: DB 쓰레드 → 큐에서 꺼내 DB 저장
 ├─ 대기: 사용자 입력 'q'까지 루프
 ├─ 종료: stop_event 설정 → 쓰레드 종료
 └─ 실행: plot_sensor_data() → 그래프 생성 및 저장
```
