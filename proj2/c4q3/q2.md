## ✅ 1. 데이터베이스 테이블 생성 (SQLite)

Python의 `sqlite3` 모듈을 사용해 `parm_data` 테이블을 생성합니다.

```python
import sqlite3

def create_table():  # 데이터베이스 테이블을 생성하는 함수 정의
    conn = sqlite3.connect("smartfarm.db")  # smartfarm.db 파일에 연결 (없으면 자동 생성)
    cursor = conn.cursor()  # SQL 실행을 위한 커서 객체 생성
    cursor.execute("""  # 테이블 생성 SQL 실행
        CREATE TABLE IF NOT EXISTS parm_data (  # 테이블이 없을 경우에만 생성
            id INTEGER PRIMARY KEY AUTOINCREMENT,  # 자동 증가하는 고유 ID (기본 키)
            sensor_name TEXT,  # 센서 이름 (문자열)
            timestamp DATETIME,  # 데이터 입력 시간
            temperature INTEGER,  # 온도 (정수)
            light INTEGER,  # 조도 (정수)
            humidity INTEGER  # 습도 (정수)
        )
    """)  # SQL 문 끝
    conn.commit()  # 변경사항 저장
    conn.close()  # 데이터베이스 연결 종료

if __name__ == '__main__':  # 이 파일이 직접 실행될 경우
    create_table()  # 테이블 생성 함수 호출
    print("✅ 데이터베이스와 테이블이 준비되었습니다.")  # 완료 메시지 출력

- `id`: 자동 증가하는 기본 키
- `timestamp`: 데이터 입력 시간
- `sensor_name`: 센서 이름 (보너스 과제를 위해 추가)
- `temperature`, `light`, `humidity`: 센서 측정값

## ✅ 2. 센서 데이터 저장 함수 `insert_sensor_data()`

```python
from datetime import datetime

def insert_sensor_data(sensor_name, temperature, light, humidity):  # 센서 데이터를 DB에 저장
    conn = sqlite3.connect("smartfarm.db")  # 데이터베이스 연결
    cursor = conn.cursor()  # 커서 객체 생성
    cursor.execute("""  # 데이터 삽입 SQL 실행
        INSERT INTO parm_data (sensor_name, timestamp, temperature, light, humidity)
        VALUES (?, ?, ?, ?, ?)
    """, (sensor_name, datetime.now(), temperature, light, humidity))  # 현재 시간 포함 데이터 삽입
    conn.commit()  # 변경사항 커밋
    conn.close()  # 연결 종료
```
좋은 질문이야! `cursor = conn.cursor()`는 **SQLite 데이터베이스와 대화하기 위한 통로를 만드는 코드**야. 좀 더 자세히 설명해볼게:

---

## 🧠 개념 설명: 커서(cursor)란?

- **커서(cursor)**는 데이터베이스에서 SQL 명령을 실행하고 결과를 가져오는 **작업자** 역할을 해.
- `conn`은 데이터베이스 연결 객체이고, `conn.cursor()`는 그 연결을 통해 **명령을 실행할 수 있는 커서 객체**를 만들어줘.

---

## 🔧 코드 흐름 예시

```python
conn = sqlite3.connect("smartfarm.db")  # DB 연결
cursor = conn.cursor()  # 커서 생성 (SQL 실행 담당자)

cursor.execute("SELECT * FROM parm_data")  # SQL 실행
rows = cursor.fetchall()  # 결과 가져오기

conn.close()  # 연결 종료
```

---

## 🔍 커서의 주요 기능

| 기능 | 설명 |
|------|------|
| `execute()` | SQL 명령 실행 (예: SELECT, INSERT, UPDATE 등) |
| `fetchall()` | SELECT 결과 전체 가져오기 |
| `fetchone()` | SELECT 결과 한 줄만 가져오기 |
| `executemany()` | 여러 개의 INSERT/UPDATE를 한 번에 실행 |

---

## 📦 비유로 이해하기

- `conn`은 **도서관**이고,
- `cursor`는 **사서**야.
- 너가 "이 책 찾아줘"라고 말하면, 사서가 요청을 처리하고 결과를 가져오는 거지.

---conn = sqlite3.connect("smartfarm.db") → 도서관에 입장
    cursor = conn.cursor() → 사서에게 도움 요청
    cursor.execute(...) → 사서에게 책을 찾아달라고 명령
    cursor.fetchall() → 사서가 책을 가져옴
    conn.close() → 도서관에서 나감

        sensor.SetData()  # 센서 데이터 설정
        temp, light, humi = sensor.GetData()  # 센서 데이터 가져오기
        timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")  # 현재 시간 문자열로 저장

        insert_sensor_data(sensor.name, temp, light, humi)  # 데이터베이스에 저장

        if humi > 90:  # 습도가 90 초과일 경우
            print(f"{timestamp} {sensor.name} — temp {temp}, light {light}, humi {RED}{humi}{RESET}")  # 빨간색으로 출력
        else:  # 습도가 90 이하일 경우
            print(f"{timestamp} {sensor.name} — temp {temp}, light {light}, humi {humi}")  # 일반 출력

        for _ in range(10):  # 10초 동안 1초씩 나눠서 대기
            if stop_event.is_set():  # 종료 이벤트 확인
                break  # 종료 이벤트가 설정되면 루프 탈출
            time.sleep(1)  # 1초 대기
```

## 🧮 1. 센서별 데이터 수 집계 쿼리

```sql
SELECT sensor_name, COUNT(*) 
FROM parm_data 
GROUP BY sensor_name
```

### 🔍 설명:

| 구문 | 의미 |
|------|------|
| `SELECT sensor_name, COUNT(*)` | 각 센서 이름과 해당 센서가 기록한 데이터의 총 개수를 선택함 |
| `FROM parm_data` | `parm_data` 테이블에서 데이터를 조회함 |
| `GROUP BY sensor_name` | 센서 이름별로 데이터를 묶어서 집계함 |

📌 결과: 각 센서가 몇 개의 데이터를 기록했는지 출력됩니다. 예:  
```
Parm-1: 120개  
Parm-2: 115개  
...
```

---

## 📊 2. 센서별 시간대별 평균 데이터 계산 쿼리

```sql
SELECT sensor_name, strftime('%Y-%m-%d %H', timestamp) AS hour,
       AVG(temperature), AVG(light), AVG(humidity)
FROM parm_data
GROUP BY sensor_name, hour
ORDER BY sensor_name, hour
```

### 🔍 설명:

| 구문 | 의미 |
|------|------|
| `SELECT sensor_name` | 센서 이름을 선택함 |
| `strftime('%Y-%m-%d %H', timestamp) AS hour` | `timestamp`에서 날짜와 시간(시 단위)만 추출해서 `hour`라는 별칭으로 사용함 |
| `AVG(temperature), AVG(light), AVG(humidity)` | 해당 시간대의 평균 온도, 조도, 습도를 계산함 |
| `FROM parm_data` | `parm_data` 테이블에서 데이터를 조회함 |
| `GROUP BY sensor_name, hour` | 센서 이름과 시간대별로 데이터를 묶어서 평균을 계산함 |
| `ORDER BY sensor_name, hour` | 센서 이름과 시간대 순으로 결과를 정렬함 |

📌 결과: 각 센서가 특정 시간대에 기록한 평균값이 출력됩니다. 예:  
```
Parm-1 2025-11-01 21시 - 평균 온도: 25.3, 조도: 7800.2, 습도: 65.1  
Parm-2 2025-11-01 21시 - 평균 온도: 24.9, 조도: 7900.0, 습도: 67.3  
...
```
