1. 단순 연결 리스트 구현
수행과제
Python 코드로 단순 연결 리스트 구조를 완성한다.
단순 연결 리스트의 이름은 linkedlist로 만든다.
추가 함수를 insert(i,value)로 추가한다.

단순 연결 리스트의 특정 항목을 삭제 할 수 있도록 삭제 함수를 delete()로 추가한다.
준비가 되었으면 원하는 음악의 목록을 단순 연결 리스트에 입력하거나 삭제해 본다.
보너스 과제
처음부터 끝까지 순차적으로 가져오는 get_list() 함수를 추가해 본다.

[Linked List 그림 설명 ](https://limecoding.tistory.com/85)

linkedlist                          # 연결 리스트 클래스 정의
├── __init__()                      # 생성자: 리스트 초기화
│   └── self.head = None            # 첫 노드를 가리키는 head 포인터
│
├── __len__()                       # 리스트 길이 반환 함수
│   ├── count = 0                   # 노드 수 카운트
│   ├── current = self.head         # 현재 노드를 head로 초기화
│   ├── while current               # 리스트 순회
│   │   ├── count += 1              # 카운트 증가
│   │   └── current = current.next  # 다음 노드로 이동
│   └── return count                # 전체 노드 수 반환
│
├── insert(data, position=None)    # 노드 삽입 함수
│   ├── if position is not None and (position < 0 or position > len(self))
│   │   └── raise IndexError        # 유효하지 않은 위치 예외 처리
│   ├── new_node = Node(data)       # 유효성 통과 후 노드 생성
│   ├── if position == 0 or self.head is None
│   │   ├── new_node.next = self.head  # 새 노드가 기존 head를 가리킴
│   │   └── self.head = new_node       # head를 새 노드로 변경
│   └── else
│       ├── current = self.head        # 현재 노드를 head로 초기화
│       ├── index = 0                  # 인덱스 초기화
│       ├── while current.next and (position is None or index < position - 1)
│       │   ├── current = current.next  # 다음 노드로 이동
│       │   └── index += 1              # 인덱스 증가
│       ├── new_node.next = current.next  # 새 노드가 현재 다음 노드를 가리킴
│       └── current.next = new_node       # 현재 노드가 새 노드를 가리킴
│
├── delete(data)                   # 노드 삭제 함수
│   ├── current = self.head         # 현재 노드를 head로 초기화
│   ├── prev = None                 # 이전 노드 초기화
│   ├── while current               # 리스트 순회
│   │   ├── if current.data == data
│   │   │   ├── if prev is None
│   │   │   │   └── self.head = current.next  # 첫 노드 삭제
│   │   │   └── else
│   │   │       └── prev.next = current.next  # 중간 또는 마지막 노드 삭제
│   │   │   └── return True                   # 삭제 성공
│   │   ├── prev = current                    # 이전 노드 이동
│   │   └── current = current.next            # 다음 노드 이동
│   └── raise IndexError                      # 삭제 실패 예외 처리
│
└── get_list()                    # 리스트 전체 반환 함수
    ├── result = []                # 결과 리스트 초기화
    ├── current = self.head        # 현재 노드를 head로 초기화
    ├── while current              # 리스트 순회
    │   ├── result.append(data)    # 데이터 추가
    │   └── current = current.next # 다음 노드로 이동
    └── return result              # 전체 리스트 반환
