# 이진트리
* 수행과제 Python 코드로 이진 트리(Binary Search Tree) 구조를 완성한다. 
* 이때 이진 트리의 이름은 binarytree로 만든다. 
* 이진 트리에 새로운 원소를 추가 할 수 있도록 추가 함수를 insert()로 추가한다. 
* 이진 트리에 원하는 값의 존재 유무를 확인 할 수 있도록 탐색 기능을 하는 함수를 find()로 추가한다. 
* 이진 트리에서 특정 원소를 삭제하는 delete() 함수를 추가한다. 
* 보너스 과제 전체 내용을 BinarySearchTree 라는 이름의 클래스로 구성해서 재사용할 수 있게 한다. 
* Python에서 기본 제공되는 명령어 이외의 별도의 라이브러리나 패키지를 사용해서는 안된다.

물론이죠! 아래는 이진 탐색 트리(Binary Search Tree)의 구조와 동작을 이해하기 쉽게 설명한 **트리 구조 주석**입니다. 이 주석은 트리의 형태와 각 노드의 관계를 시각적으로 표현한 것입니다.

### 🌳 이진 탐색 트리 구조 예시 주석

```python
# 트리 구조 예시 (삽입 순서: 50, 30, 70, 20, 40, 60, 80)
#
#           50          ← 루트 노드
#         /    \
#       30      70      ← 루트의 왼쪽/오른쪽 자식
#      /  \    /  \
#    20   40  60  80    ← 리프 노드들
#
# 규칙:
# - 왼쪽 자식 노드는 부모보다 작은 값
# - 오른쪽 자식 노드는 부모보다 큰 값
```

### 🔍 동작 설명 주석

```python
# insert(값): 트리에 새로운 값을 삽입
# find(값): 해당 값이 트리에 존재하는지 확인
# delete(값): 트리에서 해당 값을 삭제
# inorder(): 중위 순회 결과를 리스트로 반환 (오름차순 정렬된 값들)
```
좋아요! 아래는 `BinarySearchTree` 클래스의 각 메서드가 **어떻게 동작하는지**, 즉 **실행 원리**를 상세히 설명한 내용입니다. 각 메서드가 내부적으로 어떤 방식으로 작동하는지, 어떤 조건을 검사하고 어떤 결과를 반환하는지를 단계별로 풀어드릴게요.

---

## 🌱 `insert(key)` — 값 삽입

### 실행 원리
1. 먼저 `find(key)`를 호출해 **이미 존재하는 값인지 확인**합니다.
   - 존재하면 `ValueError` 예외를 발생시켜 중복 삽입을 막습니다.
2. `_insert(root, key)`라는 **내부 재귀 함수**를 사용해 루트부터 탐색을 시작합니다.
3. 현재 노드가 `None`이면, 해당 위치에 새 `Node(key)`를 생성합니다.
4. 삽입할 `key`가 현재 노드보다 작으면 왼쪽 서브트리로 재귀 호출합니다.
5. 크면 오른쪽 서브트리로 재귀 호출합니다.
6. 삽입이 완료되면 변경된 루트를 반환하여 트리 구조를 갱신합니다.

### 핵심 포인트
- 트리의 정렬 규칙(왼쪽 < 부모 < 오른쪽)을 유지합니다.
- 중복된 값은 삽입되지 않습니다.

---

## 🔍 `find(key)` — 값 탐색

### 실행 원리
1. `_find(root, key)`라는 **내부 재귀 함수**를 사용해 루트부터 탐색을 시작합니다.
2. 현재 노드가 `None`이면, 트리에 해당 값이 없다는 뜻이므로 `False`를 반환합니다.
3. 현재 노드의 값이 `key`와 같으면 `True`를 반환합니다.
4. `key`가 현재 노드보다 작으면 왼쪽 서브트리로 이동합니다.
5. 크면 오른쪽 서브트리로 이동합니다.
6. 최종적으로 `True` 또는 `False`를 반환합니다.

### 핵심 포인트
- 트리의 구조를 활용해 **불필요한 경로를 생략**하며 빠르게 탐색합니다.
- 시간 복잡도는 평균적으로 O(log n), 최악의 경우 O(n)입니다.

---

## 🗑️ `delete(key)` — 값 삭제

### 실행 원리
1. 먼저 `find(key)`를 호출해 **삭제할 값이 존재하는지 확인**합니다.
   - 없으면 `KeyError` 예외를 발생시킵니다.
2. `_delete(root, key)`라는 **내부 재귀 함수**를 사용해 루트부터 탐색을 시작합니다.
3. `key`가 현재 노드보다 작으면 왼쪽 서브트리에서 삭제를 시도합니다.
4. 크면 오른쪽 서브트리에서 삭제를 시도합니다.
5. `key`와 현재 노드가 같으면 삭제 대상입니다. 이때 세 가지 경우로 나뉩니다:

   #### 삭제 대상 노드의 상태
   - **자식이 없음** → `None` 반환
   - **자식이 하나** → 그 자식을 반환하여 부모와 연결
   - **자식이 둘** → 오른쪽 서브트리에서 **최소값 노드**를 찾아 현재 노드와 값을 교체하고, 그 최소값 노드를 삭제

6. 삭제 후 변경된 루트를 반환하여 트리 구조를 갱신합니다.

### 핵심 포인트
- 삭제 후에도 트리의 정렬 규칙을 유지합니다.
- 자식이 둘일 경우, 오른쪽 서브트리의 최소값을 선택하는 방식은 BST의 일반적인 전략입니다.

---

## 🍃 `_find_min(node)` — 최소값 찾기

### 실행 원리
1. 주어진 노드에서 시작하여 **왼쪽 자식 노드로 계속 이동**합니다.
2. 왼쪽 자식이 더 이상 없을 때, 그 노드가 해당 서브트리의 최소값입니다.
3. 해당 노드를 반환합니다.

### 핵심 포인트
- BST에서 가장 작은 값은 항상 **가장 왼쪽 노드**에 위치합니다.
- `delete()`에서 자식이 둘일 때 대체값을 찾는 데 사용됩니다.

---

## 📋 `inorder()` — 중위 순회

### 실행 원리
1. `_inorder(root)`라는 **내부 재귀 함수**를 사용합니다.
2. 중위 순회는 다음 순서로 진행됩니다:
   - 왼쪽 서브트리 순회
   - 현재 노드 방문
   - 오른쪽 서브트리 순회
3. 각 노드의 값을 리스트에 담아 반환합니다.

### 핵심 포인트
- 중위 순회 결과는 항상 **오름차순 정렬된 값 리스트**가 됩니다.
- 트리의 정렬 상태를 확인하거나 출력할 때 유용합니다.
