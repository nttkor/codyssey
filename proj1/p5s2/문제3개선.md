정확히 그렇게 하면 됩니다.
**.ui → 타입 변환(py 클래스)** 방식에서도,
**UI를 두 개 로드해서 창 전환(스위칭)** 하려면 각각을 **독립된 클래스로 정의하고**, 필요에 따라 `show()` / `hide()`를 호출해서 제어하면 됩니다.

---

## ✅ 구조 요약

예를 들어 `.ui` 파일이 이렇게 두 개 있다고 할 때:

* `calculator.ui` → `ui_calculator.py` → `Ui_Calculator`
* `engineering.ui` → `ui_engineering.py` → `Ui_Engineering`

### ✅ 클래스 2개 생성:

```python
from PyQt6.QtWidgets import QMainWindow
from ui_calculator import Ui_Calculator
from ui_engineering import Ui_Engineering

class BasicWindow(QMainWindow, Ui_Calculator):
    def __init__(self):
        super().__init__()
        self.setupUi(self)
        # 버튼 이벤트 연결 등 처리
        self.btn_mode.clicked.connect(self.on_switch)

    def on_switch(self):
        self.hide()
        self.other_window.show()
        self.other_window.activateWindow()


class EngineeringWindow(QMainWindow, Ui_Engineering):
    def __init__(self):
        super().__init__()
        self.setupUi(self)
        # 버튼 이벤트 연결 등 처리
        self.btn_mode.clicked.connect(self.on_switch)

    def on_switch(self):
        self.hide()
        self.other_window.show()
        self.other_window.activateWindow()
```

---

## ✅ 컨트롤러에서 서로 연결

```python
class AppController:
    def __init__(self):
        self.basic = BasicWindow()
        self.engineering = EngineeringWindow()

        # 서로 연결
        self.basic.other_window = self.engineering
        self.engineering.other_window = self.basic

        # 시작 모드
        self.engineering.show()
```

---

## ✅ 실행 코드

```python
if __name__ == "__main__":
    import sys
    from PyQt6.QtWidgets import QApplication

    app = QApplication(sys.argv)
    controller = AppController()
    sys.exit(app.exec())
```

## 📌 요약

| 질문                            | 답변                                                         |
| ----------------------------- | ---------------------------------------------------------- |
| UI 2개를 타입 변환 방식으로 로드해서 전환하려면? | 각각 클래스로 만들고, `.show()` / `.hide()` 로 제어하면 됩니다              |
| 서로 어떻게 연결하나요?                 | `window1.other_window = window2` 식으로 **상호 참조** 구조를 쓰면 편합니다 |
| 기존 동적 로딩보다 어떤 점이 좋은가요?        | 코드가 더 **직관적**, IDE 자동완성, 이벤트 연결이 명확해집니다                    |
