최종 기획안
사용자의 새로운 의견과 보완점을 종합하여 최종 기획안을 정리해 드립니다.

숫자 입력:

기존과 동일하게 num 변수에 숫자를 누적한다.

=를 누른 후 새로운 숫자를 입력하면 초기화한다.

연산자 입력:

num에 숫자가 있을 경우:

op1이 비었다면 num을 op1에 저장하고, operator에 연산자를 저장한다.

op1이 있다면 num을 op2에 저장하고 중간 계산을 수행한 후, op1에 결과를 저장하고 operator에 새로운 연산자를 저장한다.

num이 비어 있을 경우:

새로운 연산자가 +나 -일 경우:

+는 무시하고 현재 상태를 유지한다.

-는 다음 입력될 숫자의 부호로 간주한다. (예: 5 X 상태에서 -를 누르면 5 X - 상태로 디스플레이)

새로운 연산자가 X, /, %일 경우: operator에 새로운 연산자를 저장하고 디스플레이를 업데이트한다. (예: 5 + 상태에서 X를 누르면 5 X로 변경)

+/- 버튼:

num에 입력된 숫자가 있을 때만 동작하며, num의 부호를 바꾼다.

= 버튼:

op1과 num이 모두 있을 때만 연산을 수행하고 결과를 표시한다.

연산 후 equals_pressed 상태로 전환하여 다음 숫자 입력 시 초기화되도록 한다.

AC 버튼:

모든 변수를 초기화하고 디스플레이를 0으로 리셋한다.

코드 설명 및 보완
os.chdir(os.path.dirname(__file__)): import os와 함께 이 코드를 추가하여 스크립트가 실행되는 파일의 디렉토리로 현재 작업 경로를 변경했습니다. 이는 UI 파일을 찾지 못하는 문제를 해결해 줍니다.

QtWidgets에서 Qt로 변경: PyQT6에서는 Qt.AlignmentFlag.AlignRight처럼 특정 속성들이 Qt 모듈로 옮겨졌기 때문에 from PyQt6.QtCore import Qt를 추가했습니다.


UI 위젯명: caculator.ui 파일에서 led라는 이름의 QLineEdit 위젯과 btn_으로 시작하는 여러 QPushButton 위젯을 정의했습니다. 이 위젯들을 코드 내에서 이름으로 직접 호출하여 연결했습니다.






btn_plus_minus: +/- 버튼의 클릭 이벤트를 toggle_sign 메서드에 연결하여 현재 입력 중인 숫자의 부호를 변경하도록 구현했습니다.

연속 연산자 처리:

input_operator 메서드 내에서 self.num이 비어 있을 때의 조건을 세분화했습니다.

op == "-"일 경우, 다음 숫자의 음수 부호로 인식하게 하고 is_negative 플래그를 설정합니다.

다른 연산자가 연속으로 들어오면 기존 연산자를 변경하고 디스플레이에 반영합니다.


btn_mode: UI 파일에는 Mode 버튼이 있지만, 기획안에는 기능이 정의되어 있지 않아 임시로 all_clear 기능을 연결했습니다. 추후 다른 기능으로 확장할 수 있습니다.

이제 이 코드를 calculator.py 파일로 저장하고, 같은 폴더에 caculator.ui 파일을 두면 정상적으로 실행될 것입니다.
