#계산기 프로그램 PyQT6버전
##함수 설명
__init__():
계산기 UI를 초기화하는 함수입니다. 창 제목을 설정하고, UI를 구성하는 init_ui() 함수를 호출합니다.

init_ui():
UI 구성 요소(디스플레이 및 버튼들)를 설정합니다. 버튼의 크기, 글꼴, 위치 등을 설정하고, 버튼 클릭 이벤트를 연결합니다.

button_clicked():
각 버튼이 클릭될 때 호출되는 함수입니다. 버튼에 맞는 동작을 수행합니다. 예를 들어, 숫자 버튼은 입력을 추가하고, C 버튼은 입력을 지우고, = 버튼은 계산을 실행합니다.

toggle_sign():
+/- 버튼을 클릭할 때 호출됩니다. 입력값의 부호를 변경합니다.

percentage():
% 버튼을 클릭하면 현재 디스플레이 값에 대해 퍼센트 계산을 수행합니다. 예를 들어, 50을 0.5로 변환합니다.

evaluate_expression():
= 버튼을 클릭할 때 호출되며, 디스플레이에 입력된 수식을 계산하여 결과를 디스플레이에 출력합니다. eval()을 사용하여 수식을 계산합니다.

main():
프로그램의 시작점으로, QApplication을 초기화하고 계산기 창을 실행합니다.
물론이죠! 프로그램의 **실행 순서**를 따라가며 각 코드 블록이 어떻게 동작하는지 단계별로 설명해드릴게요.

---

### 1. **프로그램 시작 (`main()` 함수)**

```python
if __name__ == "__main__":
    app = QApplication(sys.argv)  # 애플리케이션 객체 생성
    calc = Calculator()  # 계산기 객체 생성
    calc.show()  # 계산기 UI 표시
    sys.exit(app.exec())  # 이벤트 루프 시작
```

* **`if __name__ == "__main__":`**

  * Python 프로그램이 직접 실행될 때만 이 블록이 실행됩니다.
  * 즉, 이 파일이 **직접 실행**될 때 `main()` 함수가 호출됩니다.

* **`app = QApplication(sys.argv)`**

  * PyQt 애플리케이션을 시작하려면 `QApplication` 객체가 필요합니다.
  * `sys.argv`는 프로그램 실행 시 전달된 명령줄 인자를 PyQt에서 사용할 수 있도록 합니다. 대개 GUI 애플리케이션에서는 중요하지 않지만, 필요한 경우 인자들을 사용할 수 있습니다.

* **`calc = Calculator()`**

  * `Calculator` 클래스의 인스턴스를 생성합니다.
  * 이는 계산기의 UI 및 기능을 담당하는 객체입니다.

* **`calc.show()`**

  * 계산기 UI를 화면에 표시합니다.
  * `show()`는 `QWidget`에서 상속된 메서드로, 해당 위젯(여기선 `Calculator` 클래스)이 화면에 표시되도록 합니다.

* **`sys.exit(app.exec())`**

  * `app.exec()`는 **이벤트 루프**를 시작합니다. PyQt는 이벤트 기반 라이브러리이기 때문에, `exec()`가 실행되는 동안 애플리케이션은 사용자 입력(버튼 클릭 등)을 기다리며 실행됩니다.
  * `sys.exit()`은 프로그램이 종료될 때 운영체제에 종료 상태를 반환하는 역할을 합니다.

### 2. **`Calculator` 클래스 초기화 (`__init__`)**

```python
def __init__(self):
    super().__init__()
    self.setWindowTitle("iPhone Style Calculator (PyQt6)")  # 창 제목 설정
    self.setFixedSize(300, 400)  # 창 크기 고정
    self.init_ui()  # UI 초기화 함수 호출
```

* **`__init__()`**:

  * 이 메서드는 `Calculator` 객체가 생성될 때 자동으로 호출됩니다.
  * 창의 제목을 `"iPhone Style Calculator (PyQt6)"`로 설정하고, 창 크기를 고정합니다.
  * 그런 다음, `init_ui()` 메서드를 호출하여 실제 UI 구성 요소들을 설정합니다.

---

### 3. **UI 설정 (`init_ui`)**

```python
def init_ui(self):
    self.display = QLineEdit()  # 디스플레이 영역
    self.display.setAlignment(Qt.AlignmentFlag.AlignRight)  # 오른쪽 정렬
    self.display.setReadOnly(True)  # 텍스트 입력 불가
    self.display.setFixedHeight(60)  # 높이 고정
    self.display.setFont(QFont("Arial", 24))  # 글꼴과 크기 설정
```

* **디스플레이 (`QLineEdit`)**:

  * 사용자에게 수식이나 계산 결과를 표시할 영역입니다.
  * 텍스트는 오른쪽 정렬되며, 사용자가 텍스트를 직접 입력할 수 없게 설정되어 있습니다. (읽기 전용)
  * 글꼴은 Arial로 설정하고 크기는 24px로 지정되었습니다.

```python
buttons = [
```

* 이 배열은 계산기의 버튼 배치를 정의합니다. 버튼은 여러 행과 열로 나누어져 있으며, 각 버튼의 텍스트가 정의됩니다.

```python
grid = QGridLayout()
```

* **`QGridLayout()`**:

  * 버튼을 그리드 형태로 배치하기 위한 레이아웃입니다.

```python
for btn_row in buttons:
    for btn_text in btn_row:
        button = QPushButton(btn_text)  # 각 버튼 생성
        button.setFont(QFont("Arial", 16))  # 글꼴 설정
        button.setFixedSize(60, 60)  # 버튼 크기 설정
```

* 각 버튼에 대해 **`QPushButton`** 객체를 생성하고, 텍스트, 크기, 글꼴 등을 설정합니다.
* 버튼을 클릭했을 때 호출될 메서드 `self.button_clicked`를 연결합니다.

```python
grid.addWidget(button, row, col)  # 버튼을 그리드에 배치
```

* 각 버튼을 **`grid`** 레이아웃에 추가합니다. `row`와 `col`은 버튼이 배치될 위치를 결정합니다.

### 5. **버튼 클릭 시 동작 (`button_clicked`)**

```python
def button_clicked(self):
    sender = self.sender()  # 클릭된 버튼 객체 가져오기
    btn_text = sender.text()  # 클릭된 버튼의 텍스트 가져오기
```

* 버튼이 클릭되면, \*\*`sender()`\*\*를 사용하여 클릭된 버튼을 식별하고, 버튼의 텍스트를 가져옵니다.

```python
if btn_text == 'C':
    self.display.clear()  # 디스플레이 초기화
elif btn_text == '=':
    self.evaluate_expression()  # 수식 계산
elif btn_text == '+/-':
    self.toggle_sign()  # 부호 변경
elif btn_text == '%':
    self.percentage()  # 퍼센트 계산
else:
    current_text = self.display.text()  # 현재 텍스트 가져오기
    self.display.setText(current_text + btn_text)  # 버튼 텍스트 추가
```

* 버튼 텍스트에 따라 각기 다른 동작을 수행합니다:

  * **`C`**: 디스플레이를 비웁니다.
  * **`=`**: 수식을 계산하여 결과를 디스플레이에 표시합니다.
  * **`+/-`**: 숫자의 부호를 변경합니다.
  * **`%`**: 현재 값을 100으로 나누어 퍼센트를 계산합니다.
  * 그 외의 숫자나 연산자는 디스플레이에 추가됩니다.

### 6. **부호 변경 (`toggle_sign`)**

```python
def toggle_sign(self):
    text = self.display.text()
    if text:
        if text.startswith('-'):
            self.display.setText(text[1:])  # 부호를 제거
        else:
            self.display.setText('-' + text)  # 부호를 추가
```

* 현재 디스플레이에 숫자가 있을 때, 그 숫자의 부호를 반전시킵니다. 예를 들어 `+5` → `-5`, `-3` → `+3`.

---

### 7. **퍼센트 계산 (`percentage`)**

```python
def percentage(self):
    try:
        value = float(self.display.text())  # 현재 텍스트를 실수로 변환
        self.display.setText(str(value / 100))  # 100으로 나누어 퍼센트 계산
    except:
        self.display.setText("Error")  # 오류 처리
```

* 디스플레이에 표시된 숫자를 100으로 나누어 퍼센트를 계산합니다.
* 오류가 발생하면 `"Error"` 메시지를 디스플레이에 표시합니다.

---

### 8. **수식 계산 (`evaluate_expression`)**

```python
def evaluate_expression(self):
    try:
        result = eval(self.display.text())  # 수식을 평가하여 계산
        self.display.setText(str(result))  # 계산 결과를 디스플레이에 표시
    except:
        self.display.setText("Error")  # 오류 처리
```

* **`eval()`** 함수는 수식을 **동적으로 평가**하고 계산 결과를 반환합니다. 예를 들어, `"3 + 5"`를 평가하여 `8`을 반환합니다.
* 오류가 발생하면 `"Error"` 메시지를 표시합니다.

### 요약

1. **`main()` 함수**가 프로그램의 시작점을 제공합니다. `QApplication`을 생성하고, `Calculator` 객체를 만들어 UI를 표시합니다.
2. **`Calculator` 클래스**는 UI와 버튼 동작을 관리합니다. 버튼 클릭 시, 각 버튼에 맞는 동작을 **`button_clicked()`** 함수에서 처리합니다.
3. 사용자가 버튼을 클릭하면, 해당 버튼에 맞는 동작(디스플레이 업데이트, 수식 계산 등)을 수행합니다.

이런 방식으로 프로그램은 실행되고, 사용자의 입력에 따라 실시간으로 UI가 업데이트됩니다.
