# 1) 프로그램 시작 → 메인 윈도우 뜨기

## 1-1. 엔트리 포인트

* 맨 아래:

  ```python
  if __name__ == "__main__":
      main()
  ```
* **실행 흐름**: 파이썬이 모듈을 스크립트로 실행하면 `main()` 호출.

## 1-2. `main()`

```python
app = QtWidgets.QApplication(sys.argv)
w = MainWindow()
w.show()
sys.exit(app.exec())
```

* **QApplication 생성**: Qt 이벤트 루프 준비.
* **MainWindow 인스턴스**: 여기서 대부분의 초기화가 일어남(다음 섹션).
* **show()** 후 \*\*app.exec()\*\*로 이벤트 루프 진입 → GUI 반응 시작.

> 🧠 **기술**: *PyQt6 이벤트 루프*, *Qt Widgets 기반 GUI*.
> QApplication은 **이벤트 기반** GUI의 핵심. 키 입력/클릭/타이머 등은 이벤트로 들어오고, 슬롯(함수)이 처리.

# 2) `MainWindow.__init__`—UI 로드와 각종 초기화

## 2-1. UI 로딩

```python
base_dir = os.path.dirname(os.path.abspath(__file__))
ui_path = os.path.join(base_dir, "engineering.ui")
uic.loadUi(ui_path, self)
```

* **런타임 UI 로딩**: `uic.loadUi`가 `.ui` 파일을 파싱해 \*\*현재 객체(self)\*\*에 위젯 트리를 주입.
* **장점**: 코드-UI 분리, 디자이너 파일 그대로 사용.

> 🧠 **기술**: *PyQt6.uic* — `.ui`를 파이썬 객체로 즉시 로딩. 별도 py 변환 불필요.

## 2-2. 핵심 위젯 핸들 잡기

```python
opts = QtCore.Qt.FindChildOption.FindChildrenRecursively
self.le_expr = self.findChild(QLineEdit, "le_expr", opts)
self.le_result = self.findChild(QLineEdit, "le_result", opts)
```

* 오브젝트 이름으로 **표시 창(le\_expr)**, \*\*결과 창(le\_result)\*\*를 찾아 참조 저장.

> 🧠 **기술**: *findChild(재귀)* — UI 안 깊숙한 위젯을 objectName으로 탐색.

## 2-3. 표시 글꼴 자동 맞춤 연결

```python
self.le_expr.textChanged.connect(lambda s: self._fit_font(self.le_expr, s))
self._fit_font(self.le_expr, self.le_expr.text() or "")
self.le_result.textChanged.connect(lambda s: self._fit_font(self.le_result, s))
self._fit_font(self.le_result, self.le_result.text() or "")
```

* 텍스트가 바뀔 때마다 `_fit_font()`로 글꼴 크기 조정.
* 생성 직후 **초기 1회**도 적용.

> 🧠 **기술**: *Qt 시그널/슬롯*. `textChanged(str)` → 람다 슬롯.
> 람다에 **기본인자**(예: `led=self.le_expr`)를 넣는 패턴은 여기선 `led`가 외부에서 캡처되어 문제 없지만, 버튼 바인딩에서는 `b=w` 같은 기본인자 캡처가 핵심(아래 3-1 참고).

## 2-4. 엔진/상태 준비

```python
self.engine = EngineeringCalculator()  # 공학 기능 구현 클래스(상속)
self.inv_mode = False
self._pending_clear = False  # '=' 이후 입력 처리 플래그
```

* `EngineeringCalculator`는 **공학 훅 구현**(sin/cos/…/π/²/³/%).
* `_pending_clear`는 **‘=’ 직후 다음 입력 정책**을 제어(Ans 시드 vs 새식 시작).

> 🧠 **설계 기법**: *상속 + 템플릿 메서드(hooks)*
> 기본 파이프라인은 `Calculator`가 담당, **공학 기능만 하위 클래스가 override**.

## 2-5. 버튼 바인딩/비활성/라벨 동기화

```python
self._bind_all_buttons()
self._disable_unimplemented_functions()
self._disable_2nd_rand_plusminus()
self._sync_rad_button_text()
```

* **모든 버튼** 클릭을 **하나의 디스패처**로 연결(오브젝트명 규칙/텍스트 폴백).
* 미구현/2nd/Rand/± 버튼은 **비활성 + 회색**.
* 각도 모드 버튼 텍스트(**Deg/Rad**) 동기화.

> 🧠 **기술**: *동적 디스패치(getattr)*, *스타일시트로 상태 표현*.

# 3) 버튼 클릭 → 입력/평가가 흘러가는 길

## 3-1. 전체 버튼 바인딩

```python
for w in self.findChildren(QPushButton) + self.findChildren(QToolButton):
    w.clicked.connect(lambda _=False, b=w: self.on_button_clicked(b))
```

* 모든 버튼을 **같은 슬롯**(`on_button_clicked`)으로 연결.
* `lambda _=False, b=w:`는 **루프 클로저 문제 방지**용 — 연결 시점의 버튼을 `b`에 고정.

> 🧠 **기술**: *람다 기본인자 캡처로 late-binding 회피*.

## 3-2. 디스패치 규칙 (`on_button_clicked`)

1. **objectName 우선**(`btnn_*, btnf_*, btno_*` 등 접두로 의미 구분) → `_alias()`로 내부 키 표준화 → `do_*` 핸들러 호출.
2. 실패하면 **버튼 텍스트**로 추정(`_key_from_text`) → `do_*`.

예)

* `btnn_7` → 숫자 7 → `_append_digit("7")`
* `btnf_sin` → 공학 함수 → `do_sin()`
* `btno_div` 또는 라벨 "÷" → `do_div()`

> 🧠 **기술**: *동적 디스패치*, *관례 기반 라우팅*, *텍스트 폴백*.

## 3-3. 일반 숫자/소수점

* `do_*`가 아닌 내부 유틸:

  * `_append_digit(d)` : `=` 이후 새 입력이면 **표시/결과 클리어** 후 숫자 추가.
  * `_append_dot()` : 현재 숫자 세그먼트에 이미 `.` 있으면 무시.

> 🧠 **기술**: *세그먼트 검사* — 오른쪽에서 뒤로 숫자/점만 훑어 중복 소수점 방지.

## 3-4. 공학 함수/상수

* `insert_function(name)`

  * `=` 직후면 **새 식 시작**(기존 결과 지움),
  * 앞이 값이면 **암시적 곱셈**(x) 추가,
  * `name + "("` 붙임.
* `do_pi()`는 값 뒤면 `xπ`.

> 🧠 **설계**: **암시적 곱셈**을 *표시 레벨*에서 `x`로 해결(평가 직전 `*`로 변환).

## 3-5. 사칙/괄호/제곱/퍼센트

* 사칙(`+ - x ÷`)과 제곱(`²/³`)은 **‘=’ 직후**면 `_ans_seed_if_needed(True)` → `le_expr`에 `Ans` 자동 시드.
* `(` 는 숫자 뒤면 자동으로 `x(`.
* `%`는 **숫자 뒤에서만** 허용되는 **후위 연산자**(평가 시 `×0.01`).

## 3-6. DEL/AC

* `do_del()`:

  * `sinh(`, `cosh(`, … **함수 헤더 전체를 통삭제**(접미사 고정 비교, re 미사용).
  * `²/³/%`는 1글자만 지움.
  * 그 외엔 일반 한 글자 삭제.
* `do_ac()`:

  * 표시/결과/플래그 **전부 초기화**.

# 4) `=` 누를 때—평가 파이프라인

## 4-1. 내부식 변환/괄호 자동 닫기

```python
to_eval = self._auto_closed_expr(expr_display)
to_eval = self._to_internal_expr(to_eval)  # x, × → *,  ÷ → /
```

* **표시식 기호**를 파서용으로 바꾸고, `(` 개수가 더 많으면 **자동으로 닫는 괄호** 추가.

> 🧠 **기술**: *간단한 괄호 균형 보정*.
> 깊이 카운터로 남은 `(` 수만큼 `)` 추가.

## 4-2. `Calculator.evaluate_expr()`

### (1) `_tokenize(s)`

* **정규식 없이** 문자단위 스캐너:

  * 숫자(정수/소수), `+ - * / ( )`, `π`, 후위(`² ³ %`), 식별자(영문: `sin`, `Ans`, `pi` 등)
  * `Ans` → `CONST('ans')`, `pi`/`π` → `CONST('pi')`, `sin` 등은 `FUNC('sin')`.

> 🧠 **기술**: *수제 토크나이저*, *한 글자 lookahead*, *상태 없는 단순 FSM*.

### (2) `_fix_unary_minus(tokens)`

* `-`가 **식 시작/연산자/왼괄호/함수 뒤**에 오면 **단항**으로 보고 `0 - x` 형태로 보정.

> 🧠 **기술**: *문맥 기반 변환(프리패스)*.

### (3) `_to_rpn(tokens)` — **샌딩-야드**

* 연산자 우선순위 `*/ > +-` 처리.
* `f(` … `)` 꼴은 닫는 순간 스택의 `FUNC`를 **출력**해 단항 함수로 만든다.
* 후위 연산자 `POST`는 **그대로 출력**(직전 값 뒤에 오므로).

> 🧠 **기술**: *Shunting-yard algorithm* — 중위→후위 변환의 고전 알고리즘.

### (4) `_eval_rpn(rpn, angle_mode_rad)`

* **스택 평가**:

  * `NUM/CONST` push
  * `OP`: 2항 팝 → 계산 → 푸시
  * `FUNC`: 1항 팝 → `apply_function()` 호출(라디안/도 변환 포함)
  * `POST`: 1항 팝 → `apply_postfix()` 호출(²/³/%)
* 마지막에 스택 1개 아니면 오류.

> 🧠 **설계**: 공학 기능은 전부 `EngineeringCalculator`의 **훅 구현**으로 위임.

## 4-3. 결과 처리

* 성공 시:

  * `self.engine.last_result = val` (**Ans 갱신**)
  * `le_result`에 `fmt_number(val)`로 표시
* 실패 시: `Error`
* 마지막에 `_pending_clear = True` → **‘=’ 이후 다음 입력 정책** 발동.

> 🧠 **기술**: *표시/평가 분리*. 표시에는 `x, ÷`를 쓰되 평가엔 변환.
> *예외 흐름 간단화*: 실패 시 공통적으로 `Error`.

# 5) ‘=’ 이후 이어 계산 로직 (Ans 시드)

* 사칙/제곱 `(+ - x ÷ ² ³)` → `_ans_seed_if_needed(True)`

  * `le_expr`가 비어 있으면 **자동으로 `Ans`** 채우고 그 뒤에 연산자/제곱이 붙음.
  * 하단 결과(`le_result`)는 **유지**.
* 함수(`sin` 등)는 **새 식 시작**: `_ans_seed_if_needed(False)` → 표시/결과 **클리어** 후 `sin(` 부터.

> 🧠 **UX 설계 포인트**: 일반 공학 계산기의 “Ans 이어 계산” 경험을 재현.

# 6) 각도 모드(Deg/Rad) 토글

* `do_rad()`:

  ```python
  self.engine.angle_mode_rad = not self.engine.angle_mode_rad
  self._sync_rad_button_text()  # 'Rad' or 'Deg'로 라벨 동기화
  ```
* **평가 시점**에 `apply_function()`이 참조하여 `deg → rad` 변환.

> 🧠 **기술**: *상태 플래그에 따른 런타임 분기*.
> 삼각함수 입력 자체는 동일, **평가 시**에만 모드 반영.

# 7) 메모리(MC/MR/M+/M-)

* `MC`: 0으로 초기화
* `MR`: **필요 시 암시적 곱셈** 후 **숫자 형태로 삽입**(`fmt_number`)
* `M+ / M-`: 사용값 우선순위

  1. 결과창이 숫자면 그 값
  2. 아니면 표시식을 평가해서 그 값
  3. 아니면 무시(None)

> 🧠 **설계**: 실사용 경험에 맞춘 **현실적인 우선순위**.

# 8) 글꼴 자동 축소 알고리즘

```python
def _fit_font(self, led, text):
    length = max(1, len(text or ""))
    if length <= 19:
        size = 48
    else:
        size = max(5, min(48, int(900 / length)))
    font = led.font()
    font.setBold(True)
    font.setPointSize(size)
    led.setFont(font)
```

* **19자까지 48pt**, 그 이상은 **`800/length`로 점진 축소**, **최소 12pt**.
* 두 디스플레이 모두 `textChanged` 때마다 적용.

> 🧠 **기술**: *실시간 폰트 리스폰시브*. 단순하지만 효과적.

# 9) 숫자 표시 포맷팅

* `fmt_number()`:

  * **정수처럼** 떨어지면 정수 문자열.
  * 아니라면

    * `FIXED_DECIMALS`가 지정되면 **고정 소수점**
    * 아니면 **유효숫자 `SIG_DIGITS`**(기본 12, 필요 시 15\~16 권장)

> 🧠 **기술**: *표시 포맷과 수치 계산 분리*.
> 계산은 `float`(배정밀도), 표시는 목적에 맞춰 유연히.

* **PyQt6 Widgets**

  * `QApplication`, `QMainWindow`, `QLineEdit`, `QPushButton`, `QToolButton`
  * **Signals/Slots**(예: `textChanged`, `clicked`)

  * 모든 버튼 `clicked` → **단일 디스패처** → **동적 디스패치(getattr)**

* **람다 캡처 패턴**

  * `lambda _=False, b=w: ...` 로 루프-클로저 문제 해결

* **파서/평가 알고리즘**

  * **수제 토크나이저**(정규식 미사용)
  * **단항 마이너스 보정**
  * **샌딩-야드(Shunting-yard)** 로 RPN 변환
  * **스택 기반 RPN 평가**
  * 안전(내장 `eval` 미사용), **공학 기능은 훅으로 위임**

  * `Calculator`는 파이프라인/사칙/괄호/Ans

* **UX 디테일**

  * `=` 이후 **Ans 시드**
  * **암시적 곱셈**(값 뒤 함수/괄호/π 시 `x`)
  * `(` 자동 `x(`, `DEL`의 **함수 머리 통삭제**
  * **Rad/Deg** 즉시 반영
  * **폰트 자동 축소**로 긴 수식/결과도 보기 좋게

# 11) 예시 흐름 한 번에 보기

예) `2`, `x`, `sin`, `(`, `30`, `)`, `²`, `=`

1. `2` → `_append_digit("2")` → `le_expr = "2"`
2. `x` → `do_mul()` → `'=' 직후 아님` → `"2x"`
3. `sin` → `insert_function("sin")` → 앞이 값 → `x` 추가 → `"2xsin("`
4. `(` → 값 아니다 → 그냥 `"2xsin(("`
5. `30` → 숫자 추가 → `"2xsin((30"`
6. `)` → 닫힘 → `"2xsin((30)"`
7. `²` → `_ans_seed_if_needed(True)`(해당없음) → 후위 `"²"` → `"2xsin((30))²"`
8. `=` → 내부식 변환(`x→*`, `÷→/`), 괄호 자동 닫기, 토크나이즈→샌딩야드→RPN평가, 결과 `le_result`, `Ans` 저장, `_pending_clear=True`

이후 `+`를 누르면 → `le_expr`가 비어 있으므로 \*\*자동으로 `Ans+`\*\*로 이어 계산.
