좋아! 지금 코드가 **어떻게 실행되고, 클릭마다 내부에서 무슨 일이 벌어지는지**를 실행 순서대로 쭉 풀어줄게. 필요한 함수/메서드 이름은 코드랑 정확히 맞췄어.

# 전체 실행 흐름

## 0) 모듈 로드 시

1. `import`들, 상수 `SIG_DIGITS`, `FIXED_DECIMALS`가 로드돼.
2. 숫자 포맷터 `fmt_number()`와 세 클래스(`Calculator`, `EngineeringCalculator`, `MainWindow`)가 **정의**만 되고 아직 실행은 안 돼.

## 1) 엔트리 포인트

3. 맨 아래:

   ```python
   if __name__ == "__main__":
       main()
   ```

   가 동작 → `main()` 실행.
4. `main()`:

   * `QApplication` 생성
   * `MainWindow()` 인스턴스 생성(여기서 대부분의 초기화가 이뤄짐)
   * `w.show()`로 창 띄움
   * `app.exec()`로 이벤트 루프 진입

## 2) `MainWindow.__init__` — UI 초기화 + 라우팅

5. `.ui` 로드:

   ```python
   uic.loadUi(ui_path, self)
   ```
6. 디스플레이 위젯 바인딩:

   ```python
   self.le_expr = findChild("le_expr")
   self.le_result = findChild("le_result")
   ```
7. **폰트 자동 축소** 시그널 연결:

   * `le_expr.textChanged` / `le_result.textChanged` → `_fit_font(...)`
   * 초기에도 한 번 `_fit_font(...)` 호출해서 크기 맞춰둠
8. 계산 엔진/상태:

   * `self.engine = EngineeringCalculator()`
   * `self._pending_clear = False`  (`=` 이후 입력 처리 플래그)
9. **버튼 수집**:

   ```python
   buttons = self.findChildren(QPushButton) + self.findChildren(QToolButton)
   ```
10. **핸들러 딕셔너리 구성(`self._handlers`)**

    * (a) **선점 매핑**

      * 숫자: `btnn_0`\~`btnn_9` → `lambda d=d: self._append_digit(d)`
      * 소수점: `btnn_dot` → `self._append_dot`
      * 삼각/쌍곡: `btnf_sin`…`btnf_tanh` → `lambda n=n: self._insert_func(n)`
    * (b) **자동 매핑**

      * 나머지 버튼을 한 바퀴 돌며:

        * `name = objectName()`, `tail = name.split("_", 1)[-1]`
        * `getattr(self, f"do_{tail}", None)`가 **호출 가능**이면 `h[name] = 그 메서드`
      * 예) `btno_plus → do_plus`, `btnf_pi → do_pi`, `btno_open_paren → do_open_paren` …
    * 최종적으로 `self._handlers = h`
11. **클릭 라우팅**

    * 모든 버튼의 `clicked`를 하나의 람다로 연결:

      ```python
      b.clicked.connect(lambda _=False, obj=b: self._handlers.get(obj.objectName(), lambda: None)())
      ```

      * `obj=b`로 캡처 → **late-binding 버그 방지**
      * 매핑 없으면 `lambda: None`로 **무동작**
12. 각도 버튼 텍스트 동기화: `self._sync_rad_button_text()`

    * 현재 모드에 따라 `'btno_rad'`에 `"Rad"`/`"Deg"` 표시

여기까지가 **앱 시작 시 한 번** 일어나는 흐름이고, 이후엔 유저 이벤트(클릭/입력)에 따라 동작해.

# 사용자 액션별 동작

## A) 숫자/소수점 입력

* `btnn_7` 클릭 → `self._append_digit("7")`

  1. `_clear_if_pending()`로 `=` 직후면 표시/결과 클리어
  2. `_append("7")`로 `le_expr` 뒤에 붙임
* `btnn_dot` → `_append_dot()`

  * 현재 숫자 세그먼트에 이미 `.`가 있으면 무시, 없으면 `.` 추가

## B) 공학 함수 입력 (sin/cos/tan/sinh/cosh/tanh)

* 예: `btnf_sin` → `_insert_func("sin")`

  1. `_clear_if_pending()`로 `=` 이후 정리
  2. `_maybe_mul()`로 값 뒤라면 `x` 자동 삽입(암시적 곱셈)
  3. `"sin("` 추가

## C) π, x², x³, %

* `btnf_pi` → `do_pi()`:

  * 값 뒤면 `x` 붙이고 `"π"` 추가
* `btnf_pow2`/`btnf_pow3` → `do_pow2()`/`do_pow3()`:

  * `_seed_ans_then("")`로 `=` 직후면 `Ans`로 시드
  * 값 뒤(혹은 `"Ans"`)에서만 `²`/`³` 붙임
* `btno_percent` → `do_percent()`:

  * 마지막이 **숫자**일 때만 `%` 허용

## D) 사칙/괄호

* `btno_plus/minus/mul/div` → `do_plus/minus/mul/div`

  * `_seed_ans_then("+/-/x/÷")`: `=` 직후면 `Ans`로 이어 계산
  * 표시에는 `x`, `÷` 쓰고, **평가 직전**에 `*`, `/`로 치환
* `btno_open_paren` → `do_open_paren()`:

  * 숫자 뒤면 자동으로 `"x("`, 아니면 `"("`
* `btno_close_paren` → `do_close_paren()`:

  * 그냥 `")"` 추가

## E) 시스템/평가

* `btns_ac` → `do_ac()`:

  * 표시/결과/플래그 초기화
* `btns_del` → `do_del()`:

  * 끝이 `"sinh("`, `"cos("` 같은 **함수 머리**면 **통삭제**
  * 아니면 1글자 삭제
* `btno_equal` → `do_equal()`:

  1. `expr_display = self._text()`
  2. `_auto_closed_expr(expr_display)`로 **열린 괄호 자동 닫기**
  3. `_to_internal_expr(...)`로 `x,×,÷` → `*,/` 변환
  4. `self.engine.evaluate_expr(..., self.engine.angle_mode_rad)` 실행

     * 성공: `self.engine.last_result = val`, `le_result ← fmt_number(val)`
     * 실패: `last_result=None`, `le_result ← "Error"`
  5. `_pending_clear = True` → 다음 입력 처리에 사용(Ans 시드 or 화면 초기화)

## F) 각도 모드

* `btno_rad` → `do_rad()`:

  * `self.engine.angle_mode_rad` 토글
  * 버튼 라벨 `"Rad"`/`"Deg"` 갱신
* 실제 함수 계산은 `EngineeringCalculator.apply_function()`에서:

  * `Deg`면 입력각을 `math.radians(x)`로 변환 후 `math.sin/cos/tan` 호출
  * `sinh/cosh/tanh`는 변환 없이 그대로

## G) 메모리

* `btns_m_c` → `do_m_c()` : 메모리 0
* `btns_m_r` → `do_m_r()` : 메모리 값 표시식에 삽입(필요 시 `x` 붙임)
* `btns_m_plus`/`btns_m_minus` → 현재 값(결과 → 아니면 표시식 평가)을 더하고/빼기

  * 현재 값은 `_current_value_for_memory()`가

    1. 우선 결과창 숫자 파싱
    2. 없으면 **현재 식**을 평가해 얻음(실패 시 `None` → 무시)

# 평가 엔진 내부(핵심 파이프라인)

1. **토큰화** `_tokenize(s)`

* 숫자: 부동소수(`float`)로 읽음
* 연산자: `+ - * /`
* 괄호: `(`, `)`
* 상수: `π` → `('CONST','pi')`, `"pi"`도 동일
* `Ans` → `('CONST','ans')` (없으면 0.0로 간주)
* 함수: 영문자 연속(예: `sin`, `cosh`) → `('FUNC', name)`
* 후위연산: `²`, `³`, `%` → `('POST', op)`

2. **단항 마이너스 보정** `_fix_unary_minus(tokens)`

* 식 시작/연산자/왼괄호/함수 뒤의 `-x`는 `0 - x`로 치환

3. **셔닝야드** `_to_rpn(tokens)`

* 중위 → 후위(RPN) 변환
* 함수는 `f(...)`가 닫힐 때 출력
* `POST`(후위연산)은 **토큰 순서대로 그대로 출력**되어 피연산자 뒤에 붙음
* 연산자 우선순위: `* /` > `+ -`

4. **RPN 평가** `_eval_rpn(rpn, angle_mode_rad)`

* 스택으로 처리

  * `NUM` → push
  * `CONST` → `ans`면 `last_result`(없으면 0.0), `pi`면 `math.pi`
  * `OP` → 2항 연산
  * `FUNC` → 1항 연산(삼각/쌍곡), `apply_function` 호출
  * `POST` → 1항 연산(²/³/%) `apply_postfix` 호출
* 스택에 최종 1개만 남아야 유효

# 표시/UX 보조 로직

* **폰트 자동 축소** `_fit_font`

  * 길이 ≤ 19 → 48pt
  * 길이 > 19 → `size = clamp(5, 48, 900 // length)`
  * Bold 유지
* **암시적 곱셈** `_maybe_mul()`

  * 마지막 문자가 값(숫자/`)`/`π`/`²`/`³`/`%`)이면 **함수/π/여는괄호** 앞에 `"x"` 삽입
* **`=` 이후 입력 정책**

  * `self._pending_clear = True`가 서는 순간은 `do_equal()`
  * 이후 **사칙/제곱** 입력 → `_seed_ans_then(op)`가 먼저 `Ans`로 식을 시드
  * **함수/여는괄호/π** 등은 `_clear_if_pending()`로 **새 식 시작**

---

이 흐름만 알면 디버깅도 쉬워요:

* **버튼이 안 먹는다** → `objectName`이 라우팅 규칙과 맞는지(`btnn_/btno_/btnf_`, `do_<tail>` 존재) 확인
* **계산이 이상하다** → `do_equal()`에서 변환/괄호닫기/엔진 파이프라인 순서 점검
* **폰트가 안 줄어든다** → `textChanged` 연결과 `_fit_font` 로직 확인

필요하면 특정 케이스(예: `-sin(30)+π²%`)가 어떻게 토큰→RPN→평가되는지까지 예제로도 풀어줄게.
