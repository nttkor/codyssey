주석 설명:

__init__():

이 메서드는 객체가 생성될 때 호출됩니다. 여기서 윈도우 제목, 창 크기 고정, 디스플레이 설정, 버튼 레이아웃 등의 초기 설정을 합니다.

디스플레이 설정:

QLineEdit 위젯을 사용해 계산기 화면을 만들고, setAlignment(Qt.AlignmentFlag.AlignRight)로 오른쪽 정렬을 설정합니다.

setFixedHeight(200)을 사용하여 디스플레이 높이를 고정합니다.

버튼 배치:

**buttons_top**과 **buttons_bottom**는 버튼을 두 그룹으로 나누어 배치합니다.

각 버튼은 QPushButton 객체로 생성되며, clicked.connect(self.button_clicked)로 클릭 이벤트를 연결하여 클릭했을 때 어떤 작업을 할지 정의합니다.

button_clicked():

버튼이 클릭되면 해당 버튼의 텍스트를 디스플레이에 추가합니다.

= 버튼을 클릭하면 계산 결과를 디스플레이에 표시하고, Rad나 Deg 버튼을 클릭하면 각도 단위를 변경합니다.

calculate_result():

eval()을 사용하여 디스플레이에 입력된 수식을 계산합니다. 계산 결과가 디스플레이에 나타납니다.

그리드 레이아웃 설정:

setColumnStretch()와 setRowStretch()를 사용하여 버튼들이 그리드에서 균등하게 배치되도록 합니다.

실행 결과:

계산기 화면의 디스플레이는 고정 크기이고, 버튼들은 위와 아래 그룹으로 나뉘어 각기 다른 비율로 배치됩니다.

버튼 크기는 균등하게 배치되며, 사용자가 입력할 수 있습니다.

이제 주석을 통해 각 코드의 동작을 이해하시기 쉬울 것입니다. 추가로 궁금한 점이 있으면 언제든지 물어보세요!
