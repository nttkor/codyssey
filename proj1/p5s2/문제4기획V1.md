# 기획(아키텍처 & 구현 전략)

## 1) 파일 구성

* 단일 파일: **`engineering_calculator.py`**
* 내부 구성

  1. **Calculator (기본 사칙/괄호/부호/퍼센트/메모리 등)**
  2. **EngineeringCalculator (공학 확장)** – `Calculator` 상속
  3. **MainWindow (PyQt6 UI 로더 + 버튼 자동 바인딩 + 상태관리)**

## 2) UI 요소 사용 방식

* 입력/표시 필드: **`le_expr`(수식), `le_result`(결과)**

  * 둘 다 폰트 48로 설정 (UI에도 이미 반영되어 있음)
  * `le_expr`: 입력 누적 전용(키보드 입력은 옵션), 버튼 클릭으로 토큰을 append
  * `le_result`: 계산 결과 반영
* 버튼 네이밍 규칙(이미 UI에 있음):

  * `btnn_` = 숫자/소수점 (`0~9`, `.`)
  * `btno_` = 연산자/모드 (`+,-,x,÷,(,),=,±,%,Rad`)
  * `btnf_` = 공학함수 (`sin, cos, tan, sinh, cosh, tanh, ln, log₁₀, e^x, 10^x, x², x³, 1/x, y^x, x^(1/y), √, ³√, π, e, EE …`)
  * `btns_` = 시스템/유틸 (`AC, del, m_c, m_plus, m_minus, m_r, 2nd, rand`)
* **자동 바인딩**: 모든 `QPushButton`/`QToolButton`를 순회하여 `objectName` 기반으로 **단일 슬롯**에 연결.

  * 규칙: `objectName.split('_', 1)[1]` → ex) `btnf_sin` → 키 `"sin"`
  * 실행 메소드명: `do_<키>` (예: `do_sin`, `do_plus`, `do_pow2` …)
  * 별도 맵 없이 `hasattr(self, f"do_{key}")`로 동적 디스패치

## 3) 상태 관리(모드/레지스터)

* **angle\_mode**: 라디안/디그리 토글 (`btno_rad` 버튼: “Rad” ↔ “Deg” 텍스트 변화)
* **inv\_mode (2nd)**: 고급/역함수 토글 (필요 시 라벨 교체 혹은 동작 전환)

  * 1차 버전에서는 필수 기능만: 2nd는 라벨만 유지하고 동작 미전환(선택) → 이후 확장으로 `sin ↔ asin`, `10^x ↔ logᵦ` 등 매핑 가능
* **memory**: `M` 레지스터(기본값 0.0) – `mc, m+, m-, mr` 전체 지원
* **last\_result**: 최근 결과(= 누른 뒤, `Ans` 역할로 사용 가능하도록 내부 저장)

## 4) 계산 엔진 설계

### (A) Calculator (기본기)

* **표현식 빌더**: 숫자/연산자/괄호/부호/퍼센트 추가 시 **토큰**으로 `le_expr` 문자열에 append
* **지원 연산(문제 3 요구 충족)**

  * 숫자(0\~9), 소수점
  * `+ - * /`(UI에선 `x, ÷`를 코드로 `*,'/'`로 변환)
  * 괄호 `(`, `)`
  * 부호 반전 `±` (현재 항/숫자에 unary minus 적용)
  * 퍼센트 `%` (직전 숫자를 `/100`으로 치환)
  * 삭제 `del`, 전체지우기 `AC`
* **평가 (=)**

  * **샌딩-야드(Shunting-yard) + 후위표기 스택**으로 `+ - * / ( )` 평가 (안전, `eval` 미사용)
  * 예외 시 `le_result`에 `"Error"` 표시
* **메모리(MC 관련)**

  * `m_c()` → `memory = 0.0`
  * `m_plus()` / `m_minus()` → 현재 표시값(가능하면 `le_result` 우선, 없으면 `le_expr` 평가값)을 `+/-`
  * `m_r()` → `memory` 값을 현재 입력 스트림에 삽입 (숫자처럼 append)
  * **질문 답변:** `mc`는 공학 전용 기능이 아니라 **기본 계산기 공통 기능**이므로 \*\*`Calculator`(베이스 클래스)\*\*에 넣는 게 맞음.

### (B) EngineeringCalculator (공학 확장)

* **필수 공학 메소드(문제 4 요구)** – 모두 `math` 모듈 사용, UI의 `btnf_*`와 매칭

  * **각도계 변경 반영**: `sin, cos, tan`은 현재 `angle_mode` 확인 후 `deg → rad` 변환
  * 하이퍼볼릭: `sinh, cosh, tanh`는 각도모드 무관(입력값을 실수 그대로 사용)
  * 상수: `π (pi)`, `e` 삽입
  * 거듭제곱: `x², x³, y^x(=x^y)`
  * 제곱근: `√(2√x)`, 세제곱근 `³√x`
  * 로그/지수: `ln, log₁₀, e^x, 10^x`
  * 역수: `1/x`
  * 과학표기 입력: `EE` → 현재 숫자 뒤에 `e` 삽입(`1.23e` 형태로 지수부 이어 입력)
  * 팩토리얼: `x!` (정수/비음수만 허용, 범위 체크)
* **적용 방식**

  * **두 가지 입력 패턴 모두 지원**

    1. **즉시계산형**: `sin(값)`처럼 함수 버튼을 누르면 **현재 토큰을 인자로 한 번 계산**해 결과를 바로 붙여줌
    2. **토큰삽입형**: `sin(`처럼 **함수명 + 여는 괄호**를 넣고 나중에 값을 닫고 `=`으로 평가
  * 1차 버전은 **토큰삽입형**을 기본으로(간결/예측가능). 필요 시 즉시계산형은 다음 단계로 확장.

## 5) 버튼-로직 연결 규칙(핵심)

* 모든 버튼 클릭 → `on_button_clicked(btn)`

  1. `name = btn.objectName()`
  2. `key = name.split('_',1)[1]`
  3. 메소드 탐색 순서:

     * `do_<key>()` (예: `do_plus`, `do_sin`, `do_pow2`)
     * 없으면 카테고리별 라우팅:

       * `btnn_` → `append_digit_or_dot()`
       * `btno_` → `append_operator_or_mode()`
       * `btns_` → `do_system(key)`
  4. `=` → `evaluate()`
* **대표 메소드 목록(예)**

  * `do_plus, do_minus, do_mul, do_div, do_open_paren, do_close_paren, do_equal, do_sign, do_percent, do_rad`
  * `do_sin, do_cos, do_tan, do_sinh, do_cosh, do_tanh, do_ln, do_log10, do_ex, do_10pow, do_pow2, do_pow3, do_invx, do_pow_y, do_yrootx, do_sqrt2, do_sqrt3, do_pi, do_e, do_fact, do_EE`
  * `do_ac, do_del, do_m_c, do_m_plus, do_m_minus, do_m_r, do_2nd, do_rand`

## 6) 입력 규칙 & 토큰화(안정성)

* 내부 표현은 문자열 기반이지만, **평가 직전 변환**:

  * `x` → `*`, `÷` → `/`
  * `±` 처리 → 직전 숫자에 `(-1)*` 적용 혹은 unary minus 부여
  * `%` → 직전 숫자를 `(/100)`로 변형
  * `EE` → 지수 표기 `e` 삽입 (`1.2e-3` 형태 유도)
* 평가기(샌딩-야드) 토큰: **숫자, 소수, 지수형 숫자, + - \* / ( )** 만 허용
* 평가 후 결과는 `le_result`에 표시하고, `last_result` 갱신. 필요 시 `Ans` 키워드 없이도 연산 지속 가능(연산자 누르면 직전 결과를 피연산자로 사용).

## 7) 각도 모드(Rad/Deg)

* `btno_rad` 클릭 시:

  * 상태 토글: `Rad` ↔ `Deg`
  * 버튼 텍스트 동기화
  * `sin/cos/tan` 호출 시 `deg`면 `math.radians(x)` 적용 후 `math.sin(...)`
* 하이퍼볼릭(sinh/cosh/tanh)은 라디안 개념 무관하므로 입력값 그대로 사용

## 8) 메모리(MC, MR, M+, M-)

* **클래스 배치**: `Calculator`에 구현 (공통기능)
* 동작:

  * `m_c`: 0으로 초기화
  * `m_plus` / `m_minus`: (가능하면 결과 → 없으면 현재 수식 평가) 값으로 가감
  * `m_r`: 현재 입력에 `memory` 삽입

## 9) 오류 처리 & 엣지 케이스

* 연속 연산자, 괄호 불일치, 0으로 나누기, 숫자 범위 초과, 팩토리얼 음수/실수 등 → `Error` 표시

* `AC`는 `expr/result/상태` 초기화(메모리는 유지)

# 핵심 기획(업데이트 반영)

## 1) = 동작

* `=` 누르면 **표시 결과는 `le_result`에**, **`le_expr`는 즉시 빈 문자열로 초기화**.
* `last_result`는 내부에 보존(향후 연산에 필요하면 사용 가능).

## 2) 공학 함수 입력 방식 (즉시계산형 없음)

* `sin, cos, tan, sinh, cosh, tanh, π, x², x³`만 **활성화**.
* 함수 버튼은 **토큰 삽입형**: 예) `sin(`, `cos(`, `tan(`, `sinh(` …
* **숫자/닫는괄호/상수 뒤에 함수가 오면 자동으로 곱하기 `*`(implicit multiplication) 삽입.**

  * 예) `2` 다음 `sin(` → `2*sin(`, `)` 다음 `cos(` → `)*cos(`, `π` 다음 `tan(` → `π*tan(`

## 3) 미구현 함수/버튼 처리

* 미구현 버튼은 **시각적으로 어둡게(비활성 스타일)** + **클릭 불가**로 처리.

  * `setEnabled(False)` + `setStyleSheet("color:#888;")` 등.

## 4) del(Backspace) 규칙

* 일반은 문자 1개 삭제.
* \*\*함수 토큰의 머리(`이름+(`)에서 커서가 끝에 있고, 끝 부분이 `sin(`, `cos(`, `tan(`, `sinh(`, `cosh(`, `tanh(` 중 하나로 “정확히 끝나면” → 그 **토큰 전체를 한 번에 삭제**.
* 구현 방법: **문자열 끝에서 정규식 검사** 또는 **고정 접미사 비교**.

## 5) 라디안/디그리(inv\_mode는 라벨만 유지)

* `inv_mode(2nd)`는 **라벨만 유지, 동작 전환 없음**.
* 삼각함수 계산 시 각도모드(Rad/Deg)는 최종 `=` 평가 때 반영(토큰을 AST 변환할 때 `deg→rad` 변환).

## 6) 클래스 구성(동일)

* `Calculator`: 기본 입력/사칙/괄호/%, ±, 메모리(MC/M+/M-/MR), 샌딩-야드 평가.
* `EngineeringCalculator(Calculator)`: **활성 함수만 구현**

  * `sin, cos, tan, sinh, cosh, tanh, pi(상수), pow2(x²), pow3(x³)`

# 구체 구현 포인트 & 스니펫

## A) 미구현 버튼 비활성화

```python
# 활성 함수/키만 허용
ENABLED_KEYS = {
    # 숫자/연산/괄호/시스템 등은 기존대로…
    "sin", "cos", "tan", "sinh", "cosh", "tanh",
    "pi", "pow2", "pow3"
}

def _darken_and_disable(btn):
    btn.setEnabled(False)
    btn.setStyleSheet("color:#888;")  # 필요시 더 명확히: "opacity:0.6;" 등

# UI 로딩 후 일괄 처리
```

## B) 함수 입력 시 곱하기 자동 삽입

```python
FUNC_TOKENS = {"sin", "cos", "tan", "sinh", "cosh", "tanh"}
MUL_IMPLICIT_AFTER = set("0123456789.)")  # 숫자, 닫는괄호, 소수점, 또는
# 추가: 상수 기호 처리
def _ends_with_constant(expr: str) -> bool:
    # π, e 같은 상수 토큰을 기호/문자로 넣는다면 여기에 처리
    return expr.endswith("π") or expr.endswith("e")

def insert_function(self, fname: str):
    expr = self.le_expr.text()
    if expr and (expr[-1] in MUL_IMPLICIT_AFTER or _ends_with_constant(expr)):
        expr += "*"
    expr += f"{fname}("
    self.le_expr.setText(expr)
```

각 버튼 핸들러:

```python
def do_sin(self):  self.insert_function("sin")
def do_cos(self):  self.insert_function("cos")
def do_tan(self):  self.insert_function("tan")
def do_sinh(self): self.insert_function("sinh")
def do_cosh(self): self.insert_function("cosh")
def do_tanh(self): self.insert_function("tanh")
```

## D) del(함수 헤더 통째 삭제)

```python
FUNC_HEADERS = ["sin(", "cos(", "tan(", "sinh(", "cosh(", "tanh("]

def do_del(self):
    s = self.le_expr.text()
    if not s:
        return
    # 1) 함수 머리 통째 삭제
    for header in sorted(FUNC_HEADERS, key=len, reverse=True):
        if s.endswith(header):
            self.le_expr.setText(s[:-len(header)])
            return
    # 2) 일반 1글자 삭제
    self.le_expr.setText(s[:-1])
```

> 장점: 간단/명확/오류 적음.
> 확장: 토큰 스택을 유지하면 `func(` 뿐 아니라 `pow2`, `pow3` 같은 기호도 토큰 단위로 잘라낼 수 있음.

## E) π, x², x³

* `π`: 상수는 **숫자/닫는괄호/상수 뒤**면 `*π`로 자동 곱셈.

```python
def do_pi(self):
    expr = self.le_expr.text()
    if expr and (expr[-1] in MUL_IMPLICIT_AFTER or _ends_with_constant(expr)):
        expr += "*"
    expr += "π"   # 내부 평가시 math.pi로 치환
    self.le_expr.setText(expr)
```

* `x²`, `x³`: **즉시계산 없음** → **토큰 삽입형**으로 `^2`, `^3`이 아니라 **괄호 기반**으로 안전하게:

  * 가장 최근 “완전한 항”을 감싸기가 복잡하므로, 1차 버전은 **후위 연산자 표기**를 문자열로 두고, 평가 직전에 변환:

    * `…<값>²` → `pow(<값>,2)` 로 변환
    * `…<값>³` → `pow(<값>,3)` 로 변환
  * 간단 구현: **기호 `²`, `³`를 그대로 붙이고 평가 직전에 정규식으로 치환**.

```python
def do_pow2(self): self._append_pow_suffix("²")
def do_pow3(self): self._append_pow_suffix("³")

def _append_pow_suffix(self, mark):
    expr = self.le_expr.text()
    if not expr:
        return
    # 직전에 숫자/괄호/상수/함수닫힘이 와야 의미 있음
    self.le_expr.setText(expr + mark)
```

### 평가 전 치환(핵심)

* `π` → `math.pi`
* `sin(` 등 → `math.sin(` 등 (삼각함수는 Deg면 `math.sin(math.radians(x))` 형태로 래핑)
* `²`, `³` → 직전 “피연산자”를 찾아 `pow(피연산자, 2|3)`로 치환

  * 간단 해법: **샌딩-야드 토큰화 단계에서 `²/³`를 단항 후위 연산자로 등록** → RPN 평가 시 처리
