# 📌 통합형 공학 계산기 기획 종합 정리

## 1. 실행 구조

* **파일 구성**

  * `calculator4.py` → UI 컨트롤/상태/연결/로직 호출을 모두 담당하는 통합형
  * `engineering_calculator.py` → 공학 계산 로직(삼각, 쌍곡, 제곱, 세제곱, 로그, 루트, 메모리, 각도모드 등)

* **실행 순서**

  1. `QApplication` 생성
  2. `MainWindow` 생성 → UI 로드 + 버튼 자동 연결
  3. 초기 화면: `engineering.ui` 표시
  4. 이벤트 루프 진입 → 사용자 입력에 따라 버튼 핸들러 실행

---

## 2. UI 관리

* **UI 파일**: `engineering.ui`, `caculator.ui`
* **UI 전환**: `Mode` 버튼 클릭 시 두 창을 **show/hide**로 교체
* **표시 동기화**: 창 전환 시 led 텍스트를 그대로 유지

---

## 3. 디스플레이 정책

* led(QLineEdit):

  * 읽기 전용, 우측 정렬
  * 초기값 `"0"`
  * 표시 길이에 따라 **폰트 크기 자동 조절**(10자리까지 48pt, 그 이상은 480/길이 pt, 최소 12pt)
* 결과 표시:

  * 12 유효자리(`.12g`)
  * 0 근사치는 0.0으로 처리
* 에러 상황: `"Error"` 표시

---

## 4. 입력 처리 흐름

### (1) 일반 입력

* 숫자, 사칙(`+ - * /`), 괄호, 소수점
* 단순히 문자열로 누적 → 표시만 업데이트
* `awaiting_second`(이항 연산 대기 상태)거나 `"0"/"Error"`일 경우 새 입력으로 교체

### (2) 단항 함수 / 상수

* `sin, cos, tan, sinh, cosh, tanh, x², x³, π, ln, log10, √x, 2√x, 3√x, 1/x, abs, e^x, 10^x, x!, e`
* 버튼 누르면 즉시 **현재 표시값 파싱 → 함수 호출 → 결과 표시**
* 상수(π, e)는 인자 없이 결과 반환

### (3) 이항 함수

* `x^y`
* 버튼 누르면:

  * 현재 표시값을 `op1`에 저장
  * 연산자 `"POW"` 기록
  * 디스플레이 `"0"`으로 초기화
* `=` 버튼 누르면:

  * 현재 표시값을 `op2`로 가져옴
  * `pow_xy(op1, op2)` 계산 후 결과 표시
  * 결과를 다시 `op1`에 저장(체인 연산 가능)

### (4) 특수 키

* `AC` → 모든 상태 초기화 + `"0"` 표시
* `⌫` → led 끝 문자 한 글자 삭제
* `±` → 현재 표시값 부호 반전
* `%` → 현재 표시값 ÷100

### (5) 메모리 키

* `MC` → 메모리 초기화
* `MR` → 메모리 값 불러와 표시
* `M+` → 표시값을 메모리에 더하기
* `M-` → 표시값을 메모리에서 빼기
* `MS` → 표시값을 메모리에 저장

### (6) 각도 모드

* `DEG`, `RAD` 버튼
* 엔진의 `angle_mode` 변경 → `sin/cos/tan` 계산에 반영

---

## 5. 라벨 정규화

* 버튼 라벨 변형을 모두 표준 키로 통일 → 기능 매핑에 일관성 유지
* 예시:

  * 곱셈: `×/X/* → *`
  * 제곱: `x²/x^2/X^2 → x^2`
  * 세제곱: `x³/x^3/X^3 → x^3`
  * 거듭제곱: `x^y/^/pow → x^y`
  * 루트: `√/√x/sqrt → √x`, `2√x → 2√x`, `3√x → 3√x`
  * 상수: `π/pi/PI → π`, `e/ℯ → e`
  * 로그: `log/log10/log₁₀/lg → log10`, `ln → ln`
  * 역수: `1/x/x⁻¹/x^-1 → 1/x`
  * 팩토리얼: `x!/n!/! → x!`
  * 각도: `DEG/degree → DEG`, `RAD/radian → RAD`
  * 기타: `AC/C/CE → AC`, `⌫/Backspace → ⌫`

---

## 6. 오류 처리

* 모든 수학 예외(`ValueError` 발생 시) → `"Error"`로 표시
* 처리하는 오류 종류:

  * 정의역 오류 (예: log(0), sqrt(-1))
  * 범위 초과 (예: exp(1e308))
  * 0으로 나누기
  * tan(90°)처럼 정의되지 않는 값

# 1) 문제 파악 (요구 분석)

* `caculator.ui`에 맞춘 **기본 Calculator**가 이미 있음.
* **공학용 UI(`engineering.ui`) 전용 클래스**를 별도로 만들 것:
  `EngineeringCalculator` ← (상속) ← `Calculator`
* 공학용에서 **추가된 30개 기능**을 정리하고, 이 중 **삼각/쌍곡삼각**, **π**, **x²**, **x³**를 **메서드로 구현**.
* **UI 버튼 ↔ 메서드**를 정확히 매칭.
* **MC 버튼(메모리 클리어)** 동작을 정확히 구현.
* 제약:

  * **표준 라이브러리만 사용**(수학 관련은 `math` 사용 허용, PyQt는 UI용으로만)
  * **경고/에러 출력 없이** 실행되어야 함(예외는 내부에서 처리)
  * **0으로 나누기 금지**, **범위 초과/정의역 오류** 등 **수학 예외를 모두 처리**해야 함
  * 숫자 범위/정밀도: 파이썬 `float` 한계(IEEE 754, `sys.float_info`) 고려

# 2) 아키텍처 개요 (클래스/역할)

```
engineering_calculator.py
 ├─ class Calculator:
 │    - 기본 4칙/%, 부호변환, 메모리(M/M+/M-/MR/MC) 기초 구현
 │    - 상태: op1/op2/operator/num/result 등
 │    - 공통 유틸: 에러/범위체크, 결과 포맷팅
 │
 └─ class EngineeringCalculator(Calculator):
      - 공학용 추가 기능 30개 제공(아래 목록)
      - 삼각/쌍곡삼각(라디안/도 지원), 거듭제곱/루트, 로그/지수, 팩토리얼, 상수 등
      - DEG/RAD 토글 상태 유지
      - UI 버튼과의 매핑 테이블 제공(컨트롤러에서 사용)
```

* **전략(Strategy) 패턴**: 컨트롤러가 활성 UI에 따라 `Calculator` 혹은 `EngineeringCalculator` 인스턴스를 사용.
* **표현/평가 분리**:

  * 단순 모드: **즉시연산 모델**(버튼마다 상태 머신으로 op1/op2/operator 조작)
  * 확장 모드: **표현식 파서(선택)**: 추후 시닝야드(Shunting-yard) 기반 파싱으로 확장 가능
  * 이번 과제 범위: **요구된 메서드의 정확한 동작 + 안전한 예외처리**에 초점

# 4) 구현할 메서드(요구 대상) – 시그니처/동작 정의

> 모든 메서드는 **예외/범위 검증 → 계산 → 결과 포맷/반환** 순서를 지킵니다.
> 도/라디안 변환은 `self.angle_mode`( `'DEG'` or `'RAD'` )로 제어합니다.

* `def sin(self, x: float) -> float`

  * 입력: x(현재 angle\_mode 기준)
  * 로직: `rad = x if RAD else math.radians(x)` → `math.sin(rad)`
  * 특이값 처리: `tan(90°)` 같은 불안정 각도는 **sin에서는 문제 없음**, 결과 `isfinite` 체크
* `def cos(self, x: float) -> float`

  * 로직: `math.cos(rad)`
  * 주의: **cos(90°) ≈ 0**의 **부동소수 오차**를 소수점 12자리 내로 클램프(거의 0이면 0.0 처리)
* `def tan(self, x: float) -> float`

  * 로직: `math.tan(rad)`
  * **정의역 검사**: DEG일 때 `x % 180 == 90` 근방은 **무한대(미정의)** → `ValueError("Undefined")`
* `def sinh(self, x: float) -> float` → `math.sinh(x)` (RAD/DEG 무관, x는 실수)
* `def cosh(self, x: float) -> float` → `math.cosh(x)`
* `def tanh(self, x: float) -> float` → `math.tanh(x)`

  * **오버플로**: 매우 큰 |x|에서 math.cosh/sinh는 overflow 가능 → 사전 범위 체크(대략 |x| > \~710은 e^x overflow)
* `def const_pi(self) -> float` → `math.pi` 반환
* `def square(self, x: float) -> float` → `x * x` (곱셈 전후 `isfinite` 체크)
* `def cube(self, x: float) -> float` → `x * x * x` (오버플로 체크)

> 공통 보조:

* `def _to_rad(self, x: float) -> float` (DEG→RAD)
* `def _finite(self, val: float) -> float` (not finite → `ValueError("RangeError")`)
* `def _near_zero(self, val: float, eps=1e-12) -> float` (미세 오차 정리용)

# 5) 예외/오류 처리 정책

* **0으로 나누기**: `1/x`, `/` 연산에서 `x==0` → `ValueError("ZeroDivision")`
* **정의역 오류**:

  * `sqrt(x)`: `x<0` → `ValueError("DomainError")`
  * `log(x)`: `x<=0` → `ValueError("DomainError")`
  * `tan(x)`: RAD/DEG에 따라 비정의 각도 근방은 `ValueError("Undefined")`
  * `x!`: 음수/비정수 → `ValueError("DomainError")`; 정수 n 큰 값(예: n>170)은 `OverflowError` 유사 처리
* **범위 초과**:

  * 연산 결과가 `not math.isfinite(result)` → `ValueError("RangeError")`
  * 입력 크기 사전 한도(`MAX_ABS = sys.float_info.max ** 0.5` 등) 초과 시 연산 전 선제 차단
* **표시용 메시지**:

  * UI에는 공통 `"Error"` 또는 구체 메시지(“Domain”, “Range”, “ZeroDiv”, “Undefined”) 중 선택
  * 과제 요구가 “경고 없이 실행”이므로 **print/logging 없이** 내부 예외로 처리 → 컨트롤러가 잡아 UI에 표시

# 6) 메모리 키(특히 MC) 설계

* 내부 상태:

  * `self.memory: float | None` (기본 `0.0`)
* 동작:

  * `MS(x)`: `memory = x`
  * `MR()`: `return memory or 0.0`
  * `M+ (x)`: `memory += x` (오버플로 검사)
  * `M- (x)`: `memory -= x`
  * **`MC()`**: **메모리 레지스터를 완전 초기화** → `memory = 0.0` (또는 `None`로 보고 `MR`에서 0.0 반환)
* UI:

  * MR을 누르면 디스플레이에 메모리 값이 입력값처럼 들어가도록 컨트롤러에서 처리
* 주의: MR/MC는 **연산 스택(op1/op2)** 와는 **독립**. 필요시 현재 입력(`num`)에 주입.

# 8) 컨트롤 흐름(요약)

1. 버튼 클릭 → 컨트롤러에서 \*\*현재 엔진(EngineeringCalculator)\*\*에 전달
2. **단항 함수**(예: `sin`, `x²`) → “현재 표시값/입력값”을 인자로 넘겨 계산 → 결과 표시
3. **이항 연산**(예: `x^y`) → `operator`로 보관, 다음 피연산자 입력 후 `=`에서 평가
4. 예외 발생 시 → 컨트롤러가 잡아 **“Error” 표시** + 상태 초기화(정책에 따라 최소 초기화)

# 9) 포맷/정밀도/라운딩

* 결과는 기본 `float` → 표시 전 **정규화**:

  * `math.isclose(val, 0.0, abs_tol=1e-12)`이면 `0.0`로 정리
  * 과학표기(예: `1.23e+20`)는 그대로 허용
  * 일반표기는 소수점 12\~15자리 내로 자름(요구 포맷에 맞춤)

# 10) 테스트/검증 시나리오

  * `tan(90 DEG)` → 오류
  * `ln(0), ln(-1)` → DomainError
  * `sqrt(-1)` → DomainError
  * `1/0` → ZeroDivision
  * `exp(800)` → RangeError
  * `factorial(-1), factorial(3.2), factorial(999)` → Domain/RangeError

  * `π sin(DEG)` vs `sin(RAD)` 모드 전환 검증

# 2) 이번 과제 **필수 구현 메서드** (이름·시그니처·요지)

> `math`만 사용(표준 라이브러리). 모든 메서드는 **정의역/범위/연산불능**을 검사하고 예외 발생 시 `ValueError` 등으로 던짐(컨트롤러에서 UI 처리).

* `def sin(self, x: float) -> float`:

  * `rad = x if angle_mode=="RAD" else math.radians(x)`
  * `y = math.sin(rad)` → `_near_zero(y)`로 0 근사치 보정 → `_finite(y)`
* `def cos(self, x: float) -> float`:

  * `y = math.cos(rad)` → **90° 근방 오차**는 `_near_zero`로 0 처리 → `_finite(y)`
* `def tan(self, x: float) -> float`:

  * **DEG에서 (x % 180 == 90) 근방은 미정의** → `ValueError("Undefined")`
  * `y = math.tan(rad)` → `_finite(y)`
* `def sinh(self, x: float) -> float`: `math.sinh(x)` → **overflow 검사**
* `def cosh(self, x: float) -> float`: `math.cosh(x)` → **overflow 검사**
* `def tanh(self, x: float) -> float`: `math.tanh(x)` → `_finite(y)`
* `def const_pi(self) -> float`: `return math.pi`
* `def square(self, x: float) -> float`: `y = x * x` → `_finite(y)`
* `def cube(self, x: float) -> float`: `y = x * x * x` → `_finite(y)`

> 각 메서드에서 `_finite`는 `math.isfinite`로 체크하고 아니면 `ValueError("RangeError")` 발생.

# 3) **추가로 쉽게 넣을 수 있는 메서드**(math 기반, 선택 구현 권장)

  * `ln(x)`(x>0), `log10(x)`(x>0), `exp(x)`, `ten_pow(x)`(=10\*\*x)
* 루트/멱:

  * `sqrt(x)`(x≥0), `cuberoot(x)`(음수 허용: `copysign(abs(x)**(1/3), x)`), `nth_root(x, n)`(정의역 주의)
  * `pow_xy(x, y)`(`math.pow` + 도메인/범위 검사)
* 역수/절댓값/팩토리얼:

  * `reciprocal(x)`(x≠0), `abs_val(x)`, `factorial(n)`(n∈ℕ, 너무 큰 n은 범위 에러)
* 각도/모드:

  * `set_angle_mode(mode: str)`, `toggle_angle_mode()`
* 난수 / 메모리:

  * `rand()`(표시 즉시 값 반환), `memory_store(x)`, `memory_recall()`, `memory_add(x)`, `memory_sub(x)`, **`memory_clear()`(=MC)**

# 4) **버튼 이벤트 ↔ 메서드** 매핑 전략(“UI 수정 없이”)

UI의 **objectName**이 다를 수 있으니, **텍스트 우선 + objectName 보조** 매핑으로 안전하게 연결:

## 4-1. 단항 함수(현재 표시값 → 결과 대체)

* `"sin"` → `calc.sin(cur)`
* `"cos"` → `calc.cos(cur)`
* `"tan"` → `calc.tan(cur)`
* `"sinh"` → `calc.sinh(cur)`
* `"cosh"` → `calc.cosh(cur)`
* `"tanh"` → `calc.tanh(cur)`
* `"x²"`/`"x^2"` → `calc.square(cur)`
* `"x³"`/`"x^3"` → `calc.cube(cur)`
* `"π"` → `calc.const_pi()` (피연산자 없이 상수 주입: 표시값을 π로 교체)

## 4-2. 이항/대기 연산(연산자 보관 → 다음 숫자 → `=`에서 수행)

* `"x^y"`/`"^"` → `operator="POW"` 저장 → 다음 입력을 `y`로 받고 `=` 때 `calc.pow_xy(op1, y)`

## 4-3. 보조/상태

* `"DEG"`/`"RAD"` 버튼 → `calc.set_angle_mode("DEG"|"RAD")` (UI 배지 갱신)
* 메모리:

  * `"MC"` → `calc.memory_clear()`
  * `"MR"` → `display = calc.memory_recall()`
  * `"M+"` → `calc.memory_add(cur)`
  * `"M-"` → `calc.memory_sub(cur)`
  * `"MS"` → `calc.memory_store(cur)`

> 버튼 텍스트가 다를 수 있으니, 연결 시 **라벨 정규화(lower, 공백 제거)** + **대체 표기 수용**(예: `x²`/`x^2`)을 추천.

# 5) 컨트롤러 측 입력 흐름(단항/이항)

* **단항**:

  1. 현재 표시값 `cur = parse_float(led.text())`
  2. `result = method(cur)` 혹은 상수 반환
  3. 예외 잡아 `"Error"` 표시, 정상 시 결과 표시

* **이항**(예: `x^y`):

  1. 연산자 버튼에서 `op1 = cur; operator="POW"; clear_for_next = True`
  2. 다음 숫자 입력 후 `=`에서
     `result = calc.pow_xy(op1, cur)` → 표시/상태 초기화(또는 체인연산 모드면 op1=result 유지)

# 6) 예외/범위/정밀도 정책

* **정의역**:

  * `tan(DEG)`에서 `x ≈ 90 + 180k` → `ValueError("Undefined")`
  * `ln(x), log10(x)`에서 `x ≤ 0` → `ValueError("DomainError")`
  * `sqrt(x)`에서 `x < 0` → `ValueError("DomainError")`
  * `factorial(n)`에서 `n<0` 또는 정수가 아니면 `ValueError("DomainError")`
* **0 나누기**: reciprocal/나눗셈에서 `ZeroDivision`
* **범위 초과**: 결과가 `not math.isfinite(y)` → `ValueError("RangeError")`
* **정밀도 보정**: `abs(y) < 1e-12` → 0.0로 스냅(특히 cos 90°, sin π 등)

# 7) MC 버튼 정확한 동작

* 목적: **메모리 레지스터 완전 초기화**
* 구현: `memory = 0.0` 로 리셋(또는 `None` 관리해도 MR에서 0.0 반환)
* 부작용 없음: op1/op2/operator/num 등과 **독립**
* MR은 언제나 **현재 메모리 값**을 **입력값처럼 디스플레이로 주입**하도록 컨트롤러에서 처리

# 운영 팁(추천 구조에 곁들이면 좋은 것)

* **버튼 자동 배선 유틸**: `findChildren(QPushButton)` → 라벨/객체명 정규화 → `UNARY_MAP/BINARY_MAP/SPECIAL_MAP`로 자동 연결.
* **예외 통일 계층**: 엔진은 `ValueError("DomainError"/"RangeError"/"ZeroDivision"/"Undefined")`만 던지고, 컨트롤러가 잡아 `"Error"` 표시 + 최소 상태 초기화.
* **상태 단순화**:

  * **표시 버퍼** vs **평가값** 분리(=를 누르기 전은 문자열 입력 덩어리, 단항 함수는 현재 표시값을 float로 파싱해 즉시 적용).
  * 이항 연산(`x^y`)은 `op1/operator/op2`로 **컨트롤러 보관** 후 `=`에서만 엔진 호출.
* **맵핑 중앙화**:

  * `{"sin": calc.sin, "cos": calc.cos, "x²": calc.square, "x^2": calc.square, "π": calc.const_pi, ...}`
  * UI 라벨 변경 대비: `"x²"`, `"x^2"` 둘 다 키로 등록.
* **모드 전환**: show/hide 전환 시 **버퍼·led 문자 그대로 동기화**, 폰트 스케일 재적용.
