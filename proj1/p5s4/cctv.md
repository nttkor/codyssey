## 📌 프로그램 실행 흐름

### 1. 메인 시작부
- `if __name__ == "__main__":` 에서 시작합니다.  
- `os.chdir(os.path.dirname(__file__))` → 현재 실행 위치를 스크립트 파일이 있는 폴더로 바꿉니다.  
- `problem2()` 함수를 호출합니다.  

---

### 2. problem2() 함수
- `cctv` 폴더가 없으면 `cctv.zip`을 풀어서 `cctv` 폴더를 만듭니다.  
- `MasImageHelper("cctv")` 객체를 생성합니다. (이미지 목록, HOG 보행자 검출기, Haar 얼굴 검출기를 준비)  
- 이미지가 없으면 종료합니다.  
- OpenCV 윈도우 `"CCTV Search"`를 열고, 현재 이미지를 저장할 `state = {"img": None}` 딕셔너리를 만듭니다.  
- 마우스 이벤트 콜백 함수 `on_mouse`를 정의하고 `cv2.setMouseCallback`으로 등록합니다.  

---

### 3. 메인 루프
- `helper.show_image()`로 현재 이미지를 불러와서 `idx/total` 오버레이를 붙여 화면에 표시합니다.  
- `cv2.waitKey(0)`으로 키 입력을 기다립니다.  
  - **ESC(27)** → 프로그램 종료  
  - **← (81)** → 이전 이미지 (`helper.prev_image()`)  
  - **→ (83)** → 다음 이미지 (`helper.next_image()`)  
- 키 입력에 따라 이미지를 바꾸고 다시 표시합니다.  

---

### 4. 마우스 클릭 동작
- **왼쪽 1/3 클릭** → 이전 이미지로 이동  
- **오른쪽 1/3 클릭** → 다음 이미지로 이동  
- **가운데 1/3 클릭** → 사람/얼굴 검출 실행  
  - 클릭한 위치의 **세로 구역**에 따라 민감도 선택  
    - 위쪽 → Min (낮은 민감도)  
    - 가운데 → Mid (중간 민감도)  
    - 아래쪽 → Max (높은 민감도)  
  - 검출 시작 전 `"Detecting..."` 텍스트를 화면 중앙에 표시  
  - `helper.detect_people_and_faces()` 실행 후 결과 이미지 표시  

---

### 5. detect_people_and_faces() 내부
- 입력 이미지를 받아서 **사람 + 얼굴 검출**을 수행합니다.  
- **사람 검출 과정**  
  1. 원본 이미지를 0°, -45°, +45° 회전시켜 각각 HOG 보행자 검출 실행  
  2. 검출된 박스를 다시 원본 좌표계로 변환  
  3. 축소본(0.5배)에서도 검출 후 좌표를 2배로 환산  
  4. 모든 박스를 합쳐서 **NMS(Non-Maximum Suppression)** 로 겹치는 박스를 하나로 통합  
  5. 최종 박스를 초록색 사각형으로 그림  
- **얼굴 검출 과정**  
  - 원본 이미지를 그레이스케일로 변환  
  - Haar Cascade로 얼굴 검출 후 파란색 사각형으로 그림  
- 마지막으로 `idx/total` 오버레이를 붙여 반환  

---

### 6. 종료
- ESC 키를 누르면 루프를 빠져나와 `cv2.destroyAllWindows()`로 모든 창을 닫고 프로그램이 종료됩니다.

## 2. 코드의 실행 순서 (단계별 상세 설명)

### 1단계: 초기 설정 및 압축 해제

1.  **실행 시작**: 스크립트가 실행되면 `if __name__ == "__main__":` 블록이 실행됩니다.
2.  **작업 디렉토리 변경**: `os.chdir(os.path.dirname(__file__))`를 통해 현재 스크립트 파일이 위치한 디렉토리로 작업 경로를 설정합니다.
3.  **`problem2()` 함수 호출**: 메인 프로그램 로직을 담고 있는 `problem2()` 함수를 호출합니다.
4.  **ZIP 파일 확인 및 해제**:
    * `if not os.path.exists("cctv"):`를 통해 `cctv` 폴더의 존재 여부를 확인합니다.
    * 폴더가 없으면 `unzip_file("cctv.zip", "cctv")` 유틸리티 함수를 호출하여 `cctv.zip`을 `cctv` 폴더에 압축 해제합니다.

### 2단계: `MasImageHelper` 초기화

1.  **헬퍼 객체 생성**: `helper = MasImageHelper("cctv")`를 호출하여 이미지 관리 객체를 생성합니다.
    * **`__init__`**: `cctv` 폴더 내의 모든 이미지 파일 목록을 가져와 **정렬**합니다.
    * **HOG 설정**: `cv2.HOGDescriptor()`를 생성하고, `setSVMDetector()`를 이용해 **미리 학습된 사람 검출기**(`cv2.HOGDescriptor_getDefaultPeopleDetector()`)를 설정합니다.
    * **Haar Cascade 설정**: `cv2.CascadeClassifier` 객체를 생성하고, OpenCV에 내장된 **정면 얼굴 검출 XML 파일**(`haarcascade_frontalface_default.xml`)을 로드합니다.
2.  **이미지 유무 확인**: `helper.has_images()`를 통해 폴더에 이미지가 있는지 확인하고, 없으면 프로그램을 종료합니다.

### 3단계: UI 초기화 및 메인 루프 시작

1.  **창 생성**: `cv2.namedWindow("CCTV Search", cv2.WINDOW_AUTOSIZE)`로 OpenCV 디스플레이 창을 생성합니다.
2.  **마우스 콜백 설정**: `cv2.setMouseCallback("CCTV Search", on_mouse)`를 통해 마우스 이벤트를 처리할 함수(`on_mouse`)를 등록합니다.
3.  **첫 이미지 표시**:
    * `while True:` 메인 루프가 시작됩니다.
    * `img, path = helper.show_image()`를 통해 첫 번째 이미지를 로드하고, 이미지 번호(`1/N`)를 주석으로 추가합니다.
    * `cv2.imshow("CCTV Search", img)`로 이미지를 화면에 표시합니다.
    * `state["img"] = img`에 현재 이미지를 저장합니다.

### 4단계: 사용자 입력 대기 및 이벤트 처리

메인 루프는 사용자가 키를 입력하거나 마우스를 클릭할 때까지 대기합니다.

#### A. 키보드 입력 처리 (`cv2.waitKey(0)`)

| 키 입력 | 동작 |
| :--- | :--- |
| **ESC (27)** | `break`를 통해 메인 루프를 종료합니다. |
| **왼쪽 화살표 (81)** | `helper.prev_image()`를 호출하여 **이전 이미지로 전환**합니다. |
| **오른쪽 화살표 (83)** | `helper.next_image()`를 호출하여 **다음 이미지로 전환**합니다. |

#### B. 마우스 입력 처리 (`on_mouse` 콜백 함수)

**1. 이미지 전환 (탐색)**
* **좌측 1/3 클릭**: `helper.prev_image()`를 호출하여 **이전 이미지로 전환**하고 화면을 업데이트합니다.
* **우측 1/3 클릭**: `helper.next_image()`를 호출하여 **다음 이미지로 전환**하고 화면을 업데이트합니다.

**2. 객체 검출 (중앙 클릭)**
* **중앙 1/3 클릭**: 검출을 시작합니다.
    * 우선 화면 중앙에 **"Detecting..."** 메시지를 잠깐 표시합니다.
    * 클릭한 **수직 위치(Y 좌표)**에 따라 검출 파라미터를 다르게 적용합니다:
        * **상단 1/3 (Min)**: `winStride=(6,6), scale=1.03, hitThreshold=-0.3` (가장 낮은 민감도)
        * **중앙 1/3 (Mid)**: `winStride=(4,4), scale=1.01, hitThreshold=-0.6, padding=(32,32)` (중간 민감도)
        * **하단 1/3 (Max)**: `winStride=(2,2), scale=0.95, hitThreshold=-1.0, padding=(64,64)` (가장 높은 민감도)
    * **`helper.detect_people_and_faces()`** 함수가 호출되어 검출이 실행됩니다.

### 5단계: 객체 검출 상세 과정 (`detect_people_and_faces`)

이 함수는 **사람(HOG)**과 **얼굴(Haar Cascade)** 검출을 수행합니다.

1.  **회전 기반 HOG 검출**:
    * `angles=[0, -45, 45]` 리스트에 따라 **원본, 시계 반대 방향 45도, 시계 방향 45도**로 이미지를 회전시킵니다.
    * 각 회전된 이미지에 대해 HOG 검출(`hog.detectMultiScale`)을 수행하여 바운딩 박스를 얻습니다.
    * **역변환** 행렬(`cv2.invertAffineTransform`)을 사용하여 회전된 이미지의 박스 좌표를 다시 **원본 이미지 좌표계**로 변환합니다.
2.  **축소 기반 HOG 검출**:
    * 원본 이미지를 **1/2 크기**로 축소하여 HOG 검출을 수행합니다.
    * 검출된 박스 좌표를 **2배**로 스케일링하여 원본 크기로 복원합니다.
3.  **NMS (Non-Maximum Suppression) 적용**:
    * 회전본과 축소본에서 얻은 모든 바운딩 박스에 대해 `non_max_suppression` 함수를 호출합니다.
    * **겹침 비율(`overlapThresh=0.4`)**을 초과하는 중복 박스를 제거하고 최종 박스(`final_rects`)만 남깁니다.
    * 최종 박스를 원본 이미지에 **초록색** 사각형으로 그립니다.
4.  **얼굴 Haar Cascade 검출**:
    * 원본 이미지를 회색조(`cv2.COLOR_BGR2GRAY`)로 변환합니다.
    * `face_cascade.detectMultiScale`을 호출하여 얼굴을 검출합니다.
    * 검출된 얼굴 박스를 원본 이미지에 **파란색** 사각형으로 그립니다.
5.  **주석 추가 및 반환**: 검출 결과가 표시된 이미지에 최종적으로 번호 주석을 다시 추가하여 반환합니다.

### 6단계: 프로그램 종료

사용자가 ESC 키를 누르거나, 더 이상 로드할 이미지가 없어서 메인 루프가 종료되면, `cv2.destroyAllWindows()`를 통해 모든 창을 닫고 프로그램이 종료됩니다.

## 3. 주요 함수 및 파라미터 설명

### 3.1. `cv2.HOGDescriptor.detectMultiScale()` (사람 검출)

| 파라미터 | 설명 |
| :--- | :--- |
| **`winStride`** | 검출 윈도우가 이미지 위를 이동하는 단계 크기(픽셀). 값이 작을수록 **더 촘촘하게** 검사하여 정확도는 올라가지만 속도는 느려집니다. |
| **`padding`** | 이미지 주변에 추가할 패딩(여백) 크기. 검출 영역을 확장하여 이미지 경계 부분의 객체 검출률을 높이는 데 도움을 줍니다. |
| **`scale`** | 멀티스케일 검출 시, 다음 검사 단계에서 이미지를 얼마나 축소(또는 확대)할지 결정하는 비율. `1.05`는 이전 크기의 **105%**로 축소한다는 의미입니다. 값이 작을수록 더 많은 스케일에서 검사합니다. |
| **`hitThreshold`** | HOG와 SVM 분류기의 결정 경계(Decision Boundary)에 대한 임계값. **음수** 값을 주면 분류기의 민감도가 높아져 **더 많은 객체**를 검출하지만 오검출(False Positive) 가능성이 커집니다. |

### 3.2. `cv2.CascadeClassifier.detectMultiScale()` (얼굴 검출)

| 파라미터 | 설명 |
| :--- | :--- |
| **`scaleFactor`** | 멀티스케일 검출 시, 각 이미지 스케일 단계에서 이미지 크기를 얼마나 줄일지 지정하는 값. `1.1`은 이미지 크기를 **10%**씩 줄여가며 검사한다는 의미입니다. 값이 작을수록 정확하지만 느립니다. |
| **`minNeighbors`** | 검출된 사각형들이 얼굴로 인식되기 위해 **"이웃"**으로 얼마나 많은 횟수(최소 횟수)를 가져야 하는지 정의합니다. 값이 클수록 오검출은 줄지만 미검출(False Negative)은 늘어납니다. |
| **`minSize`** | 인식할 수 있는 **가장 작은 객체(얼굴) 크기**를 지정합니다. 이보다 작은 객체는 무시됩니다. |

### 3.3. `non_max_suppression()` (NMS)

| 파라미터 | 설명 |
| :--- | :--- |
| **`boxes`** | 입력되는 바운딩 박스 목록 (`[x, y, w, h]` 형태의 리스트/배열). |
| **`overlapThresh`** | 겹침 임계값. 두 박스 간의 겹치는 면적 비율(IoU와 유사)이 이 임계값을 초과하면 **덜 중요한 박스**는 제거됩니다. 이 코드에서는 `0.4`가 사용되어 40% 이상 겹치면 제거합니다. |
