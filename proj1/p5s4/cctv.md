제공해주신 코드에 사용된 주요 함수와 클래스의 자세한 기능을 실행 순서에 따라 분석하여 설명해 드릴게요. 🛠️

## 프로그램 개요 및 사용된 기술

제공해주신 코드는 **CCTV 이미지에서 사람과 얼굴을 자동으로 검색 및 검출**하는 프로그램입니다. 이 프로그램은 최신 딥러닝 기술 대신 **OpenCV의 기본 기능과 전통적인 컴퓨터 비전 기법**을 활용하여 구현되었으며, 사용자 상호 작용을 통해 수동/자동 탐색을 모두 지원합니다.

---

## 1. 프로그램 개요 (CCTV 객체 자동 검출기)

이 프로그램은 지정된 폴더(`cctv`)에 있는 일련의 이미지 파일을 순차적으로 탐색합니다.

| 기능 | 설명 |
| :--- | :--- |
| **자동 검색** | `Enter` 키를 누르면 검색이 시작되며, 사람이 발견될 때까지 다음 이미지로 **자동 순환**합니다. |
| **일시 정지** | 1) 검색 중 `Enter` 키를 누르면 **일시 정지**됩니다. 2) 이미지에서 사람이나 얼굴이 발견되면 **자동으로 정지**하고, 콘솔에 메시지를 출력합니다. |
| **재시작/종료** | 정지 상태에서 `Enter` 키를 누르면 다음 이미지부터 검색을 **재개**합니다. 모든 이미지 검색이 완료되면 **"Finish"** 메시지를 표시하고 종료를 기다립니다. |
| **수동 탐색** | 자동 검색이 아닌 상태(초기, 일시 정지)에서는 마우스 클릭이나 화살표 키로 **수동으로** 이미지를 순환할 수 있습니다. |
| **시각화** | 검출된 사람/얼굴 객체에는 바운딩 박스를 그려 표시하며, 이미지 좌상단에 현재 이미지 번호(`N/Total`)를 표시합니다. |

---

## 2. 사용된 핵심 기술

이 프로그램은 **OpenCV (Open Source Computer Vision Library)**를 중심으로 여러 전통적인 컴퓨터 비전 기술과 배열 계산을 위한 **NumPy**를 사용합니다.

### 2.1. 객체 검출 (Detection)

| 기술 | 역할 |
| :--- | :--- |
| **HOG + SVM** | **사람 검출의 주축.** `cv2.HOGDescriptor`와 `cv2.HOGDescriptor_getDefaultPeopleDetector()`를 사용하여 이미지에서 **HOG(Histogram of Oriented Gradients) 특징**을 추출하고, 미리 학습된 **SVM(Support Vector Machine)**으로 사람 객체를 분류하여 검출합니다. |
| **Haar Cascade** | **얼굴 검출.** `cv2.CascadeClassifier`에 미리 학습된 `haarcascade_frontalface_default.xml`을 로드하여 이미지에서 **Haar-like Features**를 이용해 얼굴을 검출합니다. |
| **Multi-scale Search** | **검출률 향상.** HOG 검출 시 이미지의 **원본, 축소본, 회전본**을 모두 사용하여 다양한 크기와 각도의 사람을 놓치지 않고 찾습니다. |

### 2.2. 후처리 및 안정화

| 기술 | 역할 |
| :--- | :--- |
| **NMS (Non-Maximum Suppression)** | **겹침 박스 제거.** `detectMultiScale` 과정에서 하나의 객체에 대해 여러 개의 바운딩 박스가 생성될 수 있는데, NMS 함수는 **겹침 임계값(`0.3`)**을 기준으로 겹치는 박스들을 제거하고 가장 정확한 박스만 남깁니다. |
| **NumPy** | **행렬 연산.** NMS 과정에서 바운딩 박스들의 좌표 계산, 면적 계산, 정렬 등에 사용되며, 이미지 회전 후 좌표를 원본 이미지로 되돌리는 **역변환 행렬 계산**에도 활용됩니다. |

### 2.3. 기타 OpenCV 유틸리티

| 기술 | 역할 |
| :--- | :--- |
| `cv2.cvtColor`, `cv2.resize` | 이미지의 색상 공간 변환(BGR → Gray), 이미지 크기 조절(축소) 등에 사용됩니다. |
| `cv2.putText`, `cv2.rectangle` | 화면에 텍스트 주석(번호, 메시지)이나 바운딩 박스를 그리는 데 사용됩니다. |
| `cv2.waitKey` | 프로그램의 실행 흐름을 제어하며, 사용자로부터 키 입력을 받는 역할을 합니다. |

## 2. 객체 검출 핵심 함수 (NMS)

| 함수 | 소속 | 기능 | 자세한 설명 |
| :--- | :--- | :--- | :--- |
| `non_max_suppression` | 사용자 정의 | **겹치는 박스 제거 (NMS)** | 객체 검출 결과로 나온 여러 개의 겹치는 바운딩 박스들 중에서 가장 점수가 높은 (이 코드에서는 가장 아래쪽의) 박스만 남기고, **겹침 임계값(`overlapThresh=0.3`)**을 초과하는 나머지 박스들을 제거하여 최종 검출 결과를 깔끔하게 정리합니다. |

## 3. `MasImageHelper` 클래스의 주요 메서드

이 클래스는 이미지 관리, 순환, 주석 추가, 객체 검출의 모든 기능을 담당합니다.

| 메서드 | 기능 | 자세한 설명 |
| :--- | :--- | :--- |
| `__init__` | **초기화** | HOG 검출기(`cv2.HOGDescriptor`)와 Haar Cascade 분류기(`cv2.CascadeClassifier`)를 로드하고, `cctv` 폴더 내 이미지 목록을 가져와 인덱스 0으로 설정합니다. |
| `show_image` | **이미지 로드 및 준비** | 현재 `self.index`에 해당하는 이미지 파일을 로드하고, 이미지 번호 주석을 추가한 후, 이미지와 파일 경로를 반환합니다. |
| `next_image` / `prev_image`| **이미지 인덱스 순환** | 다음/이전 이미지로 인덱스를 변경합니다. `next_image`는 검색이 끝날 때 멈추도록 **순환하지 않고**, `prev_image`는 수동 탐색을 위해 순환합니다. |
| `annotate` | **주석 및 메시지 추가** | 이미지 좌상단에 현재 이미지 번호(`idx/total`)를 표시하고, 필요 시 중앙에 **"Detecting..."** 또는 **"Finish"**와 같은 메시지를 크게 표시합니다. |
| `detect_people_and_faces`| **핵심 검출 로직** | HOG와 Haar Cascade를 결합하여 사람/얼굴을 검출합니다. |

## 4. 핵심 검출 및 제어 함수

| 함수 | 소속 | 기능 | 자세한 설명 |
| :--- | :--- | :--- | :--- |
| `hog.detectMultiScale` | OpenCV HOG | **HOG 기반 사람 검출** | HOG 특징과 SVM 분류기를 사용하여 이미지에서 사람의 특징 패턴을 찾습니다. 이 코드에서는 **회전본**과 **축소본** 이미지에도 적용하여 검출률을 높입니다. |

| `cv2.waitKey` | OpenCV (`cv2`) | **키 입력 대기 및 화면 업데이트** | 지정된 시간(밀리초) 동안 키 입력을 기다립니다. **`0`**이면 무한정 대기하고, **`1`**이나 **`10`** 같은 작은 값이면 짧게 대기 후 다음 코드를 실행하며 화면을 업데이트하는 용도로 쓰입니다. |
| `cv2.rectangle` | OpenCV (`cv2`) | **사각형 그리기** | 검출된 객체의 위치에 사각형(바운딩 박스)을 그려 시각적으로 표시합니다. |
제공해주신 코드는 **OpenCV (컴퓨터 비전 라이브러리)**를 사용하여 CCTV 이미지 폴더를 순회하며 **사람과 얼굴**을 자동으로 검출하는 프로그램입니다.

전체 프로그램은 크게 **초기화 및 유틸리티**, **객체 검출 클래스 (`MasImageHelper`)**, 그리고 **메인 실행 함수 (`problem2`)** 세 부분으로 나뉩니다.

## 💻 1. 프로그램 초기 실행 및 설정

### `if __name__ == "__main__":` 블록

1.  **작업 디렉토리 변경:** 스크립트가 실행되는 디렉토리로 작업 경로를 설정합니다.
2.  **`problem2()` 호출:** 메인 함수가 시작됩니다.

### `problem2()` 함수의 초기화 단계

1.  **압축 해제 확인:** `cctv` 폴더가 없으면 `cctv.zip` 파일의 압축을 해제합니다.
2.  **Helper 생성:** `MasImageHelper("cctv")` 객체를 생성하여 이미지 목록과 OpenCV 검출기(HOG, Haar Cascade)를 초기화합니다.
3.  **윈도우 생성:** `cv2.namedWindow("CCTV Search", ...)`를 통해 이미지 출력 창을 생성합니다.
4.  **상태 변수 초기화:**
    * `is_searching = False`: **엔터 키를 눌러야** 자동 검색이 시작되는 초기 상태입니다.
    * `is_paused_on_find = False`: 사람 발견으로 일시 정지된 상태가 아닙니다.
    * `search_finished = False`: 검색이 완료되지 않았습니다.
5.  **마우스 콜백 설정 (`on_mouse`):** 마우스 왼쪽 클릭 시 화면의 왼쪽/오른쪽 영역을 클릭하면 **수동으로** 이전/다음 이미지로 순환하도록 설정합니다. (단, 이 기능은 현재 자동 검색 상태와 무관하게 작동합니다.)

## 🔍 2. 메인 루프 실행 (`while True`)

프로그램은 무한 루프를 돌면서 키 입력을 기다리거나, `is_searching` 상태에 따라 자동 검색을 수행합니다.

### A. 초기/수동 상태 (`is_searching`이 `False`일 때)

1.  `helper.show_image()`를 통해 현재 인덱스의 이미지를 로드하고 이미지 번호 주석을 추가합니다.
2.  `cv2.imshow("CCTV Search", img)`로 이미지를 화면에 표시합니다.
3.  `key = cv2.waitKey(0)`: **무한정 대기**하며 사용자의 키 입력을 기다립니다.
    * **ESC (27):** 루프 종료.
    * **Enter (13):** `is_searching`을 `True`로 바꾸고 **자동 검색을 시작**합니다.
    * **화살표 키/마우스 클릭:** 이미지를 수동으로 순환합니다.

### B. 자동 검색 중 (`is_searching`이 `True`일 때)

이 상태는 **자동으로** 다음 단계를 순서대로 실행합니다.

1.  **'Detecting...' 표시:**
    * 현재 이미지에 **"Detecting..."** 메시지를 노란색으로 표시합니다.
    * `cv2.waitKey(1)`을 짧게 호출하여 화면을 강제로 업데이트하고 다음 단계로 즉시 넘어갑니다.
2.  **객체 검출 (`helper.detect_people_and_faces` 호출):**
    * `detect_people_and_faces` 함수가 실행되어 이미지에서 **HOG**와 **Haar Cascade**를 이용해 사람과 얼굴을 찾습니다.
    * 검출된 박스들(HOG, 얼굴)을 하나로 합친 후 **NMS**(`overlapThresh=0.3`)를 적용하여 겹치는 박스를 정리합니다.
    * 결과 이미지(박스 포함)와 **사람 발견 여부**(`people_found`)를 반환합니다.
3.  **검출 결과 표시:** 박스가 그려진 이미지를 화면에 표시합니다.
4.  **사람 발견 시:**
    * `people_found`가 `True`이면, 콘솔에 발견 메시지를 출력하고 `is_paused_on_find`를 `True`로 설정합니다.
    * `cv2.waitKey(0)`: **무한정 대기**하며 **Enter 키**가 눌리기를 기다립니다. (일시 정지 상태로 전환)
5.  **사람 미발견 시:**
    * `helper.is_last_image()`를 확인합니다.
    * **마지막 이미지이면:** `search_finished`를 `True`로 설정하고 검색을 종료합니다.
    * **마지막 이미지가 아니면:** `helper.next_image()`를 호출하여 **다음 이미지로 자동으로 넘어갑니다.**

## 🛑 3. 종료 및 재시작 (Enter 키 로직)

**Enter 키 (13)**는 프로그램의 상태를 전환하는 핵심 제어 키입니다.

| 현재 상태 | Enter 키 입력 시 동작 | 상태 변화 |
| :--- | :--- | :--- |
| **자동 검색 중** (`is_searching=True`) | 자동 검색 **일시 중지** | `is_searching = False` |
| **발견 후 정지** (`is_paused_on_find=True`) | 다음 이미지로 이동 후 자동 검색 **재개** | `is_paused_on_find = False`, `is_searching = True` |
| **초기 수동 상태** (`is_searching=False`) | 자동 검색 **시작** | `is_searching = True` |
| **검색 완료** (`search_finished=True`) | 프로그램 루프 **종료** | `break` |

---

## ✅ 4. 검색 완료 상태

`search_finished`가 `True`가 되면, 화면에 **크고 노란색의 "Finish" 메시지**가 표시됩니다. 이때 `cv2.waitKey(0)`로 대기하며, 사용자가 **ESC**를 누르거나 **Enter**를 눌러야 프로그램이 최종 종료됩니다.
