좋은 질문입니다!
**멀티프로세싱 환경에서 `q` 입력 시 즉시 프로세스 종료**가 되지 않는 문제는 많은 사람들이 겪는 공통된 문제인데, 이유와 함께 **해결 방법**을 아래에 정리해드릴게요.

---

## 🔍 문제 요약

```python
multiprocessing.Process(target=mc.get_sensor_data)
```

이 방식으로 실행된 함수 내부는 `while self.running.is_set():` 같은 루프로 돌고 있음.
**`self.running.clear()`를 호출해도 이 값은 다른 프로세스의 메모리 공간과 공유되지 않습니다.**

그래서 `q`를 눌러도 프로세스 내부에서는 종료 신호를 알 수 없고,
`p.terminate()`로 강제 종료해야만 멈추는 문제가 생깁니다.

---

## ✅ 해결 방법: `multiprocessing.Event()`를 **프로세스 간 공유**

### 📌 핵심 아이디어:

* `multiprocessing.Event()` 객체는 **프로세스 간 상태 공유가 가능한 객체**입니다.
* 이걸 `MissionComputer` 클래스에 전달하고, 모든 루프가 `event.is_set()`을 검사하게 하면,
* 메인 프로세스에서 `event.clear()`만 해도 모든 프로세스가 **즉시 루프를 빠져나와 종료**됩니다.

---

## ✅ 완전 작동 예시 (즉시 종료됨)

아래는 핵심 부분만 발췌한 코드입니다.

### 1. `MissionComputer` 생성자에서 공유 이벤트 사용

```python
class MissionComputer:
    def __init__(self, shared_event):
        self.ds = DummySensor()
        self.env_values = {}
        self.running = shared_event
        ...
```

### 2. 각 메서드에서 `self.running.is_set()` 확인

```python
def get_sensor_data(self):
    while self.running.is_set():
        ...
```

### 3. 메인에서 `shared_event` 전달

```python
def run_processes():
    shared_event = multiprocessing.Event()
    shared_event.set()

    mc1 = MissionComputer(shared_event)
    mc2 = MissionComputer(shared_event)
    mc3 = MissionComputer(shared_event)

    processes = [
        multiprocessing.Process(target=mc1.get_mission_computer_info),
        multiprocessing.Process(target=mc2.get_mission_computer_load),
        multiprocessing.Process(target=mc3.get_sensor_data)
    ]

    for p in processes:
        p.start()

    # q 누르면 event 비활성화 → 모든 프로세스 내부 루프 탈출
    try:
        while True:
            if input("종료하려면 'q' 입력: ").strip().lower() == 'q':
                shared_event.clear()
                break
    except KeyboardInterrupt:
        shared_event.clear()

    # 종료 대기
    for p in processes:
        p.join()

    print("모든 프로세스 정상 종료됨.")
```

---

## 🧪 결과

* `q` 누르면 `shared_event`가 `False`로 바뀌고,
* 각 프로세스 내부의 `while self.running.is_set()` 조건이 False가 되어 `break`됨,
* **즉시 자연 종료**됨. `terminate()`를 호출할 필요 없음.

---

## ✅ 추가 팁

* 프로세스에서 너무 오래 대기하는 `sleep()`이 있다면, `sleep(1)`처럼 짧게 나누는 것도 방법입니다.
* `terminate()`는 **안전하지 않게 프로세스를 죽이기 때문에**, 가능하면 위 방법처럼 **`Event`로 자연 종료**를 유도하는 게 좋습니다.
