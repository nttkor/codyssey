## 코드 설명서: **ZipCrypto 암호화 해독 (비밀번호 검증)**

### 1. **`check_password_fast` 함수 개요**

이 함수는 주어진 **비밀번호**가 **ZipCrypto 암호화 방식**으로 암호화된 **헤더 정보**를 정확하게 복호화할 수 있는지 **빠르게 검증**하는 기능을 수행합니다. 비밀번호가 올바르면 **체크 바이트**가 **예상 값과 일치**하는지 확인하는 방식으로 **빠른 검증**을 수행합니다.

### 2. **`check_password_fast` 함수 흐름**

#### (1) **비밀번호 초기화 및 키스트림 생성** (`self.init_keys` 호출)

```python
self.init_keys(password.encode() if isinstance(password, str) else password)
```

* **`self.init_keys(password)`**:

  * 이 함수는 주어진 **비밀번호**를 이용해 **세 개의 키**(`keys[0]`, `keys[1]`, `keys[2]`)를 초기화합니다.
  * **비밀번호 바이트**마다 `self.update_keys()` 함수가 호출되어 세 개의 키를 **갱신**하고, 이 갱신된 키들로 **키스트림**을 생성합니다.
  * 비밀번호를 **바이트 배열**로 변환하여 **키스트림**을 생성하는 과정을 통해 **암호화된 데이터**를 복호화할 수 있는 **키가 준비**됩니다.

#### (2) **암호화된 헤더에서 첫 11바이트 복호화**

```python
for i in range(11):
    self.decrypt_byte(encrypted_header[i])
```

* **헤더 복호화**:

  * Zip 파일의 **12바이트 헤더**에서 **첫 11바이트**를 복호화합니다.
  * 복호화는 **XOR 연산**을 사용하여 `self.decrypt_byte()` 함수가 하나씩 수행합니다. 이때 **키스트림**은 비밀번호로 초기화된 **세 개의 키**를 바탕으로 생성됩니다.
  * `self.decrypt_byte()`는 **XOR 연산**을 사용하여 **암호화된 바이트**를 **평문으로 변환**하는 함수입니다.

#### (3) **체크 바이트 복호화 및 검증**

```python
check_byte = self.decrypt_byte(encrypted_header[11])
return check_byte == check_byte_expected
```

* **체크 바이트 복호화**:

  * 12번째 바이트는 **체크 바이트**로, 이 값을 복호화하여 **예상된 값**(`check_byte_expected`)과 비교합니다.
  * **체크 바이트**는 **CRC-32 값**을 간접적으로 나타내는 값이며, **암호화된 데이터**가 정확하게 복호화되었는지 확인하는 데 사용됩니다.
* **체크 바이트 검증**:

  * 복호화된 **12번째 바이트**(`check_byte`)와 **예상된 체크 바이트**(`check_byte_expected`)가 **일치**하면, **비밀번호가 맞다는 것**을 의미합니다.
  * 일치하지 않으면 **비밀번호가 틀린 것**이므로, 복호화가 실패한 것으로 간주합니다.

### 3. **핵심 함수 설명**

#### (1) **`init_keys` 함수**: 비밀번호로 키 초기화

```python
def init_keys(self, password):
    """비밀번호로 키 초기화"""
    self.reset_keys()
    for byte in password:
        self.update_keys(byte)
```

* **`self.reset_keys()`**:

  * 이 함수는 **세 개의 키**(`keys[0]`, `keys[1]`, `keys[2]`)를 **초기값**으로 리셋합니다. 기본 값은 `0x12345678`, `0x23456789`, `0x34567890`입니다.
* **`for byte in password`**:

  * 주어진 비밀번호의 **각 바이트**마다 `update_keys(byte)` 함수를 호출하여 **세 개의 키**를 갱신합니다.
* **`update_keys(byte)`**:

  * `update_keys` 함수는 각 **바이트**를 사용하여 **세 개의 키**(`keys[0]`, `keys[1]`, `keys[2]`)를 **갱신**합니다. 이 갱신된 키들은 **키스트림을 생성**하는 데 사용됩니다.

#### (2) **`update_keys` 함수**: 키 갱신

```python
def update_keys(self, byte):
    """3개의 키 업데이트"""
    self.keys[0] = self.crc32_update(self.keys[0], byte)
    self.keys[1] = ((self.keys[1] + (self.keys[0] & 0xFF)) * 134775813 + 1) & 0xFFFFFFFF
    self.keys[2] = self.crc32_update(self.keys[2], (self.keys[1] >> 24) & 0xFF)
```

* **`crc32_update`**:

  * 이 함수는 **CRC32 연산**을 통해 각 키를 **업데이트**합니다. 각 바이트에 대해 **키**를 변환하여 **키스트림을 동적으로 생성**합니다.
* **`keys[0]`**, **`keys[1]`**, **`keys[2]`**:

  * **`keys[0]`**: CRC32 연산을 사용하여 키를 업데이트합니다.
  * **`keys[1]`**: `keys[0]`의 **하위 8비트**를 사용하여 **선형 변환** 후 업데이트합니다.
  * **`keys[2]`**: `keys[1]`의 **상위 8비트**를 사용하여 **다시 CRC32 연산**을 수행하여 업데이트합니다.

#### (3) **`decrypt_byte` 함수**: 한 바이트 복호화

```python
def decrypt_byte(self, enc_byte):
    """한 바이트 복호화"""
    temp = (self.keys[2] & 0xFFFF) | 2
    keystream = ((temp * (temp ^ 1)) >> 8) & 0xFF
    plain = enc_byte ^ keystream
    self.update_keys(plain)
    return plain
```

* **XOR 연산**:

  * `decrypt_byte` 함수는 암호화된 **한 바이트**를 복호화합니다. 복호화는 **키스트림**과 **XOR 연산**을 사용하여 이루어집니다.
* **키스트림 생성**:

  * `keystream`은 `keys[2]`를 기반으로 계산된 **키스트림**입니다. 이 **키스트림**을 사용하여 **암호화된 바이트**(`enc_byte`)와 **XOR 연산**을 하여 복호화된 데이터를 반환합니다.

### 4. **이론 설명**

#### **ZipCrypto 암호화와 복호화**:

* **ZipCrypto**는 **대칭키 암호화 방식**을 사용합니다. 즉, 동일한 키를 사용하여 **암호화**와 **복호화**를 모두 처리합니다.
* 이 암호화 방식은 **세 개의 키**(`keys[0]`, `keys[1]`, `keys[2]`)를 사용하여 **키스트림**을 생성하고, 이 키스트림을 **XOR 연산**에 사용하여 **데이터를 복호화**합니다.
* 비밀번호가 주어지면 **키스트림 생성**에 필요한 **세 개의 키**가 **비밀번호에 따라 업데이트**됩니다.

#### **CRC 체크**:

* \*\*CRC (Cyclic Redundancy Check)\*\*는 **데이터 무결성**을 확인하는 데 사용됩니다. 복호화된 데이터의 **CRC 값**이 헤더에 저장된 CRC 값과 일치하면 **복호화가 정확하게 이루어졌**다고 확인할 수 있습니다.
* **체크 바이트**는 복호화가 정확히 이루어졌는지 확인하는 중요한 지표로 사용됩니다.

### 5. **전체 흐름 요약**

1. **비밀번호 입력** → 비밀번호로 **세 개의 키**(`keys[0]`, `keys[1]`, `keys[2]`) 초기화.
2. **12바이트 헤더**의 첫 11바이트를 **XOR 연산**을 사용하여 복호화.
3. **12번째 바이트** (체크 바이트) 복호화 → 예상한 체크 바이트와 비교하여 **비밀번호 검증**.
4. **체크 바이트**가 일치하면 비밀번호가 **맞다는 것**을 확인.
